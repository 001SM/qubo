# QUBO 不等式约束编码：超立方体下三角法（一元松弛）

> 2026-09-11 整理。来源：用户早期对不等式约束 QUBO 编码的思考笔记
> （"常量数-1为变量超立方体维数，取超立方体超下三角即可获得小于等于的qubo，
> 取常量与超立方体相减方程的次方减去超立方下三角即可获得大于等于qubo约束"），
> 本文档为重新推导后的完整梳理。

## 0. 记号

- 约束对象：sum_{i=1}^{n} x_i <= C 或 >= C，其中 x_i in {0,1}，C 为正整数常量
- 可推广到加权约束 w·x（见第 4 节）
- 松弛变量 y_j in {0,1}，j = 1..m，构成 m 维超立方体 {0,1}^m

## 1. 核心恒等式（"下三角"的来源）

对任意二进制变量组 u：

    (sum_k u_k)^2 = sum_k u_k + 2 * sum_{k<l} u_k u_l

即：**平方 = 对角线（线性项）+ 2 x 严格下三角（二次项）**。
因为 u^2 = u（二进制），交叉项恰好只出现一次，位于外积矩阵的严格下三角。

推论（超立方体的下三角型）：

    T(y) = sum_{j<l} y_j y_l = C(|y|, 2)   （组合数，只依赖海明重量）

- T(y) = 0 当且仅当 |y| <= 1：天然的"至多选一"罚项
- 这个恒等式是把"算术约束"翻译成"QUBO 矩阵"的桥梁

## 2. <= 约束的构造

引入一元松弛 y in {0,1}^m（m >= C；若约束为严格 < C，或已知 sum x >= 1，则 m = C-1 精确）。

罚项：

    P_<= (x, y) = (sum_i x_i + sum_j y_j - C)^2

QUBO 展开（记 z = (x_1..x_n, y_1..y_m) 拼接向量，共 n+m 维）：

    P_<= = (1 - 2C) * sum_k z_k  +  2 * sum_{k<l} z_k z_l  +  C^2

矩阵形式：
- 线性项（对角）：全部 1 - 2C
- 二次项（严格下三角）：全部 +2，即全 1 外积的下三角 x 2
- 常数：C^2（可省略，不影响 argmin）

精确性证明（无伪解）：
- 若 sum x = w <= C：取 |y| = C - w，则 P = 0
- 若 w > C：sum x + sum y - C >= w - C >= 1，则 P >= 1
- 故 P 的零点集 = 可行解集，松弛变量自动补齐差值

## 3. >= 约束的构造

### 视角 A（直接：超立方体以负号进入方程）

    P_>= (x, y) = (sum_i x_i - sum_j y_j - C)^2,   y 维数 m' >= n - C

展开：

    P_>= = (1-2C) sum x + (1+2C) sum y
           + 2 T(x) + 2 T(y) - 2 sum_{i,j} x_i y_j + C^2

要点：x-y 交叉块的下三角系数是 **-2**（<= 情形为 +2）。
>= 与 <= 的唯一区别 = 松弛块符号翻转，导致 x-y 交叉下三角由加变减。
这就是原笔记中"减去超立方下三角"的含义。

精确性：
- sum x = w >= C：取 |y| = w - C，P = 0
- w < C：sum x - sum y - C <= w - C <= -1，P >= 1

### 视角 B（取补："常量与超立方体相减"）

令 z_i = 1 - x_i（变量与常量 1 相减取补），则

    sum x >= C  <=>  sum z <= n - C

套用第 2 节 <= 构造（右端换为 n - C）：

    P = (sum z + sum y - (n-C))^2 = (n - sum x + sum y - n + C)^2 = (C - sum x + sum y)^2

与视角 A 的罚项完全相同（差一个整体符号，平方后一致）。两种视角殊途同归。

## 4. 推广：加权约束 w·x <= C

罚项 (sum_i w_i x_i + sum_j y_j - C)^2。
记系数向量 c = (w_1..w_n, 1..1, -C)，最后一维对应常数项变量 z_0 = 1，则：

    (c · z)^2 = sum_k c_k^2 z_k + 2 sum_{k<l} c_k c_l z_k z_l

**通用配方：QUBO = diag(c^2) + 2 x (c c^T 的严格下三角)**。
<= 加全 1 的 y 块；>= 把 y 块系数翻负。所有线性不等式约束的罚项都归结为这一句话。

Ising 形式（s = ±1）：代入 x = (1+s)/2 即得，结构不变。

## 5. "维数 = 常量 - 1"的说明

一元松弛需覆盖松弛值域 [0, C]，严格需要 m = C 个变量。出现 C - 1 的两种情况：
1. 约束实际为严格不等式 sum x < C（即 <= C-1），值域 [0, C-1]，恰好 C-1 个变量
2. 问题另有 sum x >= 1 的保证，全零点 x = 0 不会出现（此时 m = C-1 时唯一的
   误差点是 x 全零、y 全一，罚项 = 1 而非 0）

>= 方向对偶：需要 m' = n - C（取补视角下即补约束的常量）。

## 6. 一元 vs 二进制松弛（与 v1 ConstraintEncoder 的关系）

qaoa_versions/qaoa_iterative.py 的 ConstraintEncoder.add_linear_constraint 使用
二进制松弛 s = sum_k 2^k y_k（默认 slack_bits=3）。

| 方案 | 辅助变量数 | 精确性 | 系数特征 |
|------|-----------|--------|---------|
| 一元（本文档） | C（或 C-1） | 精确 | 全部 ±2，均匀，退火/QAOA 友好 |
| 二进制 2^k | ceil(log2(C+1)) | 精确（比特覆盖足够时） | 量级悬殊（最大 2^{2k}），能量地形差 |

一元方案是 Lucas (2014) / D-Wave knapsack、portfolio 场景的标准做法；
C 较大时可换二进制省变量，但需注意系数量级对收敛的影响。

### v1 修正方案（2026-09-11 已实施，qaoa_iterative.py ConstraintEncoder）
- add_at_most_one：删掉线性项，罚项 = P·Σ_{i<j} x_i·x_j（纯下三角），零点集恰为至多选一
- add_at_least_one：改用松弛版 P·(Σx − Σy − 1)²，y 取 n−1 个辅助变量
  （"至少选一"不存在 n≥3 时的二次精确罚项，必须引入松弛或度 n 多项式）
- **修复后回归测试 8/8 PASS**（tests/test_constraint_encoder_fix.py）：
  4 个编码器零罚点集全枚举验证 + 辅助变量分配 + n_vars 缺失保护全过
- 顺带修复第三个 bug：add_linear_constraint 的 le/ge 分支旧版未实际引入
  松弛变量（等效按等式惩罚），现按二进制松弛 s=Σ2^k·y_k 正确实现

## 9. 实用注意事项与改进

1. **维数优化**：>= 需 n−C 个辅助变量，C > n/2 时用取补视角转成 <=(n−C)，
   维数取 min(C, n−C)
2. **罚权重下界宽松**：违反 k 次罚项增长 k²·P，目标收益至多线性 k·Δmax，
   故只需 P > Δmax（单变量最大边际收益），无需随 k 调整
3. **系数量级**：线性项 |1±2C| 随 C 增大，约束哈密顿量谱宽 O(C²)；
   SA 无碍（温度尺度可调），QAOA 建议 cost 项归一化（除以 C²）再调角度
4. **仅整数精确**：权重/右端为实数时需定标取整，取整方向错误会把边界可行点误判，
   实用中最大的坑；负权重需扩大松弛值域到 C + Σ|w_i<0||w_i|
5. **多约束辅助变量爆炸**：r 个约束共 Σ C_r 个辅助变量，LP/MPS 大规模场景
   可换二进制松弛（v1 现状，省变量但系数量级悬殊），小规模优先一元
6. **退化性无害**：每个松弛值有 C(m,s) 种表示，零能态多；
   SA 单比特翻转即可在可行域内移动（能隙 1·P）；QAOA 振幅虽分散但冗余态
   映射到同一 x，最终测量无影响

### SA 实战的三个层次（关键工程结论）

| 方案 | 结果 | 结论 |
|------|------|------|
| 朴素 SA 直接退火完整 QUBO（全零初值） | 1640/2668，gap 39% | **不可用**：谱宽 O(C²)，y 块线性项 ~1−2C≈−900 |
| 贪心零能初值 + 高温慢冷（T0=2e5→0.01, 1.2M 步） | 2668，gap=0 | **可用**：从可行域内起步，避免跨 O(C²) 能垒 |
| x 空间 SA + 解析罚 max(0, w·x−C)²·P | 2668，gap=0 | **最优实践**：一元松弛的 min_y 有闭式，y 可整体消元 |

### 高维实操要点（实证）

1. **初值必须零能化**：先跑 LP/贪心得到可行 x，构造 y=|C−w·x| 个 1 作为初值；
   从随机初值出发要翻越 P·w_i² 量级能垒，C 大时基本翻不过去
2. **y 可消元**：min_y (w·x±|y|−C)² = max(0, viol)² 是闭式（一元松弛独有，
   二进制松弛做不到），经典算法（SA/禁忌/局部搜索）建议直接在 x 空间搜索；
   y 块只在需要真正 QUBO 形式（量子退火/QAOA/D-Wave）时引入
3. **谱宽归一化**：完整 QUBO 进量子机前，罚项整体除以 C²（同时 P/C² 仍需
   > Δmax/C²），否则 mixer/cost 角度失衡——与第 9 节理论预判一致，实验证实
4. 计数约束（w=1）能隙均匀为 1·P，加权约束能隙为 w_i²·P——权重悬殊时
   大权重变量的翻转更难，SA 接受率可按 w_i 定标

## 11. 快速复用（伪代码）

```python
def encode_le(var_ids, C):
    # sum(x) <= C，一元松弛
    y_ids = new_vars(C)          # 或 C-1，见第 5 节
    terms = {}
    for v in var_ids + y_ids:
        add_linear(v, 1 - 2*C)
    for a, b in all_pairs(var_ids + y_ids):
        add_quad(a, b, 2)
    add_const(C*C)

def encode_ge(var_ids, C):
    # sum(x) >= C
    y_ids = new_vars(len(var_ids) - C)
    for v in var_ids:
        add_linear(v, 1 - 2*C)
    for v in y_ids:
        add_linear(v, 1 + 2*C)
    for a, b in all_pairs(var_ids):
        add_quad(a, b, 2)
    for a, b in all_pairs(y_ids):
        add_quad(a, b, 2)
    for a in var_ids:
        for b in y_ids:
            add_quad(a, b, -2)   # 下三角被减去
    add_const(C*C)
```
