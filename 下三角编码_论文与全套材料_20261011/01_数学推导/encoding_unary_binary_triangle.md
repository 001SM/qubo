# 一元松弛 / 二元松弛 与 下三角装配：流程、思路、原理

整理日期：2026-09-12

---

## 0. 一句话总览

```
带约束的 0/1 问题
   ↓ ① 松弛编码（把不等式变成等式，引入辅助变量 y）
   ↓ ② 平方罚项（(…)² × λ，把约束"搬"进目标函数）
   ↓ ③ 展开 + 下三角装配（利用 z² = z，写成 QUBO/Ising 矩阵）
无约束 QUBO/Ising 模型 → 交给退火类求解器（量子退火 / 模拟退火 / 迭代消元）
```

---

## 1. 为什么需要罚项

QUBO/Ising 求解器只能处理**无约束**的二次型最小化：

```
min  E(z) = Σ_i Q_ii·z_i + Σ_{i<j} Q_ij·z_i·z_j ,   z ∈ {0,1}
```

而实际问题是"在约束下优化"。标准做法是把约束**软化**成惩罚项加进目标：

```
min  E(z) = c·x  +  Σ_r λ_r · [第 r 条约束被违反的程度]
```

只要 λ 足够大，**任何违反约束的解的能量都会高于任何可行解**，最优解必然落在可行域内。
这就是"精确罚函数"思想（Zangwill 1967）：存在 λ₀，当 λ ≥ λ₀ 时无约束最优解 = 原问题最优解。

## 2. 第一步：把不等式变成等式（松弛编码）

原约束一般形如：

```
Σ_j a_j x_j  ≤  C      (≤ 型)
Σ_j a_j x_j  ≥  C      (≥ 型)
Σ_j a_j x_j  =  C      (等式)
```

引入**非负整数松弛量 s ≥ 0**，把不等式写成等式：

```
≤ 型:   Σ_j a_j x_j + s = C      s ∈ [0, S],  S = C − Σ_j min(0, a_j)
≥ 型:   Σ_j a_j x_j − s = C      s ∈ [0, S],  S = Σ_j max(0, a_j) − C
等式:   直接 Σ_j a_j x_j = C（不需要松弛）
```

S 是松弛量的**取值范围**（保证存在使等式成立的 s）。接下来把整数 s 用**二进制变量**表示，这就是"一元/二元化"的区别。

### 2.1 一元编码（unary / one-hot）

```
s = y_1 + y_2 + ... + y_S           （S 个辅助变量，系数全为 1）
```

- 变量数：**S 个**（随约束右端线性增长）
- 系数特征：二次项系数小（都是 1 的量级）
- 退化性：s = v 有 C(S, v) 种表示（组合数），零能态极多
- 优点：系数小 → 数值稳定；能隙均匀（单比特翻转改变 s 恰好 1）
- 缺点：变量数大，约束右端大时会爆炸（我们实测 ramos3 需要 8748~78649 个辅助变量）

### 2.2 二元编码（binary / 二进制展开）

```
s = 1·y_1 + 2·y_2 + 4·y_3 + ... + w_m·y_m      （二进制权重）
    w = [1, 2, 4, ..., 2^(m-2), S − (2^(m-1) − 1)]
    最后一位取"余量"，保证恰好覆盖 [0, S] 而不越界
```

- 变量数：**⌈log₂(S+1)⌉ 个**（对数级）
- 系数特征：二次项系数大（2^k 量级）→ 需要谨慎选 λ，存在数值风险
- 退化性：几乎无退化（每个值唯一表示）
- 优点：变量数少，规模可控
- 缺点：系数跨度大 → 谱宽大，罚权/温度定标更敏感

### 2.3 对比表

| 维度 | 一元编码 | 二元编码 |
|------|---------|---------|
| 辅助变量数 | S（线性） | ⌈log₂(S+1)⌉（对数） |
| 二次项系数量级 | 小（1 的量级） | 大（2^k） |
| 表示退化 | 严重（C(S,v) 种） | 无 |
| 数值稳定性 | 好 | 差（需调 λ） |
| 适用 | 小右端约束、量子硬件（能隙均匀） | 大规模、变量数受限场景 |
| 实测 | ramos3 需 7.9 万个辅助变量 → 不可行 | ramos3 需 8748 个 → 可用 |

## 3. 第二步：平方罚项 + 下三角装配

对每条约束（系数向量 a，含辅助变量；常数 d）：

```
罚项 = λ · ( Σ_i a_i z_i + d )²
```

展开平方（**这是下三角装配的来源**）：

```
(Σ_i a_i z_i + d)²
  = Σ_i a_i² z_i²                     ← 对角项（每个变量单独平方）
  + 2 Σ_{i<j} a_i a_j z_i z_j          ← 交叉项（每对变量只算一次）
  + 2d Σ_i a_i z_i                     ← 线性项（平方展开的交叉项）
  + d²                                 ← 常数项
```

关键一步：因为 z ∈ {0,1}，有 **z² = z**，所以 `a_i² z_i² = a_i² z_i`，平方项退化回线性项。

于是得到 QUBO 装配公式：

```
对角（线性）项：  Q_ii += λ·( a_i² + 2·d·a_i )
上三角交叉项：    Q_ij += λ·2·a_i·a_j          (i < j)
常数项：          const += λ·d²
```

### 3.1 为什么叫"下三角/上三角"

QUBO 的交叉项本质是**无向**的（z_i·z_j = z_j·z_i）。如果 i、j 两个位置都存一份，
求能量时 `Σ_i Σ_j Q_ij z_i z_j` 会把每一对**算两次**，等于把 λ 放大了一倍。

解决办法：**只在对角线的一侧存交叉项**（习惯上用严格上三角 i<j，或严格下三角 i>j），
另一侧留 0。这样：

```
E(z) = Σ_i Q_ii z_i  +  2·Σ_{i<j} Q_ij z_i z_j     （上三角存储，求能量时乘 2）
```

我们实现里就是"**只填 i<j，装配时系数为 2λa_ia_j，求能量时用 z^T Q z**"，
两种写法等价（`z^T Q z = Σ_i Q_ii z_i + 2Σ_{i<j}Q_ij z_i z_j`，因为 z²=z）。

### 3.2 与"一元松弛"的等价闭式（可选优化）

一元松弛有个额外性质：`min_y (Σa x ± |y| − C)²` 有闭式解：

```
min_y ( … )²  =  max(0, 违约量)²
```

即辅助变量可以**解析消掉**，只留违约量的平方。这条性质只有一元编码有
（二进制编码做不到，因为"最接近的松弛值"不一定落在可达点上）。
它在经典求解器里很有用（可以直接在 x 空间搜索），但如果目标是构造
**标准 QUBO/Ising 模型**（喂给量子退火/迭代消元），就必须保留显式辅助变量。

## 4. 第三步：罚权 λ 怎么定

两条下界（最小化问题）：

```
① 可行性优先：λ 必须让"任何可行解"优于"任何不可行解"
      λ > Δmax_obj / viol_min²
      Δmax_obj = 单次翻转引起的目标最大变化；viol_min = 最小非零违约量
② 与温度匹配：λ 与 T 必须同量级，否则 SA 会冻结或乱走
```

我们的取值：

```
行归一化： a_rj ← a_rj / s_r ，  s_r = max(max_j|a_rj|, |lb_r|, |ub_r|, 1)
逐行罚权： λ_r = min( 2·cmax / viol_unit_r² , 1e4·cmax )
           viol_unit_r = min_j |a_rj|（该行最小单翻转违约量）
           cmax = max_j |c_j|
```

经验：λ 过小 → 约束不被满足；λ 过大 → **所有移动都被拒绝，搜索冻结**
（我们踩过：λ = 1000·cmax 时 SA 在 60 秒内接受 0 次移动）。

## 5. 第四步：QUBO → Ising（如果要上量子硬件）

```
z_i = (1 + s_i)/2 ,  s_i ∈ {−1, +1}
```

代入 QUBO 得到 Ising 模型 `H = Σ h_i s_i + Σ J_ij s_i s_j`：

```
J_ij = Q_ij / 4
h_i  = Q_ii/2 + Σ_{j≠i} Q_ij/4
const 项会多出 ΣQ_ii/2 + Σ_{i<j}Q_ij/4
```

量子退火（D-Wave）和 QAOA 都吃这个形式；经典 SA 直接用 QUBO 形式更省事。

## 6. 完整流程串起来（我们现在的实现）

```
① 解析 MPS → 全 0/1 变量空间（固定变量折叠、整数变量二进制展开、行归一化）
② 逐约束加松弛变量（一元或二元）→ 得到约束的系数向量 a 与常数 d
③ 下三角装配：Q_ii += λ(a_i²+2da_i)，Q_ij += 2λa_ia_j (i<j)，const += λd²
④ 得到完整 QUBO (h, Q, const)，规模 = 原变量数 + 辅助变量总数
⑤ 交给**迭代消元全局退火**：
     每轮：跑 K 次 SA → 统计每个变量的投票 → 高共识变量固定并消元 → 缩图 → 重复
⑥ 得到 0/1 解 → 还原原始变量空间 → **独立校验约束可行性** → 报目标值与 gap
```

## 7. 常见坑

| 坑 | 现象 | 对策 |
|----|------|------|
| 交叉项双侧存储 | 罚权被隐式放大 2 倍 | 只用严格上三角（或下三角）存一份 |
| 忘记 z² = z | 对角项多算 a_i² 的平方 | 装配时对角用 a_i²，而不是保留 z_i² |
| λ 过大 | SA 完全不接受移动（冻结） | λ ≈ 2·cmax/viol_unit²，与 T 同量级 |
| λ 过小 | 约束被违反 | 提高 λ 或用逐行 λ_r |
| 一元编码用于大右端 | 辅助变量爆炸（几万~几十万） | 改二元编码（对数级） |
| 二元编码不取余量 | 无法表示 [0,S] 中某些值 → 约束永远差一点 | 末位权重取 S − (2^(m−1) − 1) |
| 行尺度差异大 | 某些行实际"不受约束" | 行归一化 + 逐行 λ_r |
| 辅助变量计入目标 | 目标值被污染 | 统计目标时只取原变量部分 |

---

## 8. 一句话总结

- **一元化**：把松弛量摊成 S 个 0/1 变量，系数小、退化多、变量多；
- **二元化**：把松弛量写成二进制权重，变量少、系数跨度大、需调 λ；
- **下三角**：平方展开后用 z²=z 把平方项收回线性项，交叉项只在三角一侧存一份，
  避免重复计数——这就是"装配规则"的全部内容。

## 9. 超立方体视角：平方罚项 = "2 维超立方体取超下三角"

（2026-09-12 补。用户澄清：第 3 节的"下三角"只是 m=2 的特例，
真正的结构是**把一个幂展开成对称张量（超立方体），再取其中的非降序单形（超下三角）**。）

### 9.1 超立方体 = 幂展开的对称张量

设约束涉及变量集 S，把幂展开：

```
(Σ_{i∈S} a_i x_i)^m = Σ_{i1,...,im ∈ S} a_{i1}···a_{im} · x_{i1}···x_{im}
```

右端是一个 m 阶张量（m 维超立方体，边长 |S|），共 |S|^m 个有序项。

**关键：张量里的变量就是原 Ising 模型的变量本身，不是新引入的**。
约束只是在同一批变量上再叠加一层关系，所以"超立方体的每个维度（每条边）
就是 Ising 的一个变量"，变量名完全一致。

### 9.2 超下三角 = 非降序单形（完整，含重复下标）

乘法可交换，故 x_{i1}···x_{im} 只取决于**多重集**。取非降序代表元
`i1 ≤ i2 ≤ ... ≤ im` 去重，得到的就是"超下三角"：

```
项数：|S|^m  →  C(|S| + m − 1, m)
```

**这不是"严格下三角"（i1 < i2 < ... < im）那一条线，而是一个完整单形**，
包含所有重复下标的情形：a1·a1·a2、a3·a3·a3 …… 都必须算进去。

### 9.3 降阶机制：x² = x 把重复下标塌缩

0/1 变量满足 x^k = x (k ≥ 1)，带重复下标的项自动降阶：

| 不同下标个数 k | 例子 | 降阶后 | 落在哪一层 |
|---|---|---|---|
| 1 | a3·a3·a3 | a3³ x3 → a3 x3 | 线性项 |
| 2 | a1·a1·a2 | a1²a2 x1x2 | 二次项 |
| 3 | a1·a2·a3 | 6a1a2a3 x1x2x3 | **真三次项** |
| k | … | … | 真 k 次项 |

**这就是"必须取完整维度"的原因**：重复下标的项降阶后贡献到线性/二次层，
若只取严格单形，这些系数会缺，整个多项式就错了（与第 7 节"忘记 z²=z"是同一件事）。

**结论**：m 阶张量最终按 k = 不同下标个数分层，**只有 k ≥ 3 的项**才是
Ising 装不下的"真高次项"。

### 9.4 m = 2 就是我们现在的平方罚项

```
(Σ a_i z_i + d)²
  = Σ_i a_i² z_i                  ← 非降序单形中 i=j 的 n 项（降阶为线性）
  + 2 Σ_{i<j} a_i a_j z_i z_j     ← i<j 的 C(n,2) 项（二次）
  + 2d Σ a_i z_i + d²
```

非降序单形 = {i=j 的 n 项} ∪ {i<j 的 C(n,2) 项}，完全吻合。
**所以"平方罚项"就是 2 维超立方体取超下三角。**

### 9.5 ≤ / ≥ 型的精确违反指示

对 0/1 变量，初等对称多项式有恒等式：

```
e_k(x) = Σ_{i1<i2<...<ik} x_{i1}···x_{ik} = C(S, k),   S = Σ_i x_i
```

（从 S 个 1 里选 k 个的方案数就是 C(S,k)。）

| 约束型 | 违反条件 | 精确违反指示 | 最高阶 |
|---|---|---|---|
| ≤ 型 Σx ≤ C | S ≥ C+1 | `e_{C+1}(x) = C(S, C+1)`：S ≤ C 时恒 0，S ≥ C+1 时严格正且单调增 | **C+1 元** |
| ≥ 型 Σx ≥ C | S ≤ C−1 | 取补变量 y = 1 − x 转为 ≤ 型，或用 (C − Σx) 的对偶展开 | **C−1 元** |

**"常量决定超立方体维数"的机制就在这里**：右端 C 直接决定幂展开到几阶。

> 待确认：原话"常量数−1 为维数"对应的是 ≥ 型（C−1）；若指 ≤ 型则应为 C+1。
> 两种情形都已列出，需要用户确认是哪一支。

### 9.6 高维项的扁平化（二次化）——文献

k ≥ 3 的真高次项不能直接进 Ising，需要**二次化（quadratization）**：
引入辅助变量 w，把 x_i x_j x_k 写成 w·x_k，并加罚项强制 w = x_i x_j。
这就是"通过扁平化增加约束，把高维相乘化成最多两变量相乘"。

| 文献 | 年份 | 内容 |
|---|---|---|
| Rosenberg | 1975 | 最早的归约：三次项 → w·x_k + 约束 w = x_i x_j |
| Kolmogorov & Zabih | 2004 | 高阶 MRF 可用图割最小化的条件（子模性） |
| Ishikawa | 2011 | 高阶 MRF → 一阶（K 个辅助变量的"线性"编码） |
| Anthony, Boros, Crama, Gruber | 2016 | 对称伪布尔函数二次化；辅助变量下界 Ω(√n)（DAM 203:1-12） |
| Boros, Crama, Rodríguez-Heck | 2020 | 紧致二次化构造（JOCO 39:687-707） |
| **Verma, Lewis, Kochenberger** | **2021** | **Efficient QUBO transformation for Higher Degree Pseudo Boolean Functions**（arXiv:2107.11695）—— 最贴合"扁平化"描述 |
| Tanburn, Okada, Dattani | 2015 | 不加辅助量子比特的多体项降阶（能量惩罚 gadget） |

### 9.7 与我们现有实现的关系

- 现有 `qubo_build.py` 走的是 **二元松弛 + 平方罚项**，即 9.4 的 m=2 情形，
  外加显式松弛变量把不等式转成等式。
- 超立方体这条思路**不用松弛变量**：直接用 `e_{C+1}`（或其对偶）作违反指示，
  由约束变量自身的高次多项式表示，再做二次化。
- 取舍：省掉松弛变量（避免大右端爆炸），代价是引入二次化辅助变量 + 附加约束；
  对**小右端 C**（C = 2、3）尤其划算。
