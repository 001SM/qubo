## 1. 理论部分（全部穷举验证 PASS）

### 1.1 中心格归属

超立方体（m 阶张量，边长 n）的"完全中心格"= `(c,c,...,c)`，`c=(n+1)/2`，
**只在 n 为奇数时存在**，且落在对角线上。

| n | m | 中心格 | 完整下三角项数 | 严格下三角项数 | 中心格在哪 |
|---|---|---|---|---|---|
| 3 | 2 | (2,2) | 6 | 3 | 只在完整里 |
| 3 | 3 | (2,2,2) | 10 | 1 | 只在完整里 |
| 4 | 2 | 不存在（n 为偶） | 10 | 6 | — |
| 5 | 3 | (3,3,3) | 35 | 10 | 只在完整里 |

**结论**：用户记忆中的"2×2 取 1 个格"对应**严格下三角**（C(2,2)=1）；
"取 4 个格"对应**4 个变量的 3 阶张量**（C(4,3)=4）。
即：**下三角区域从"中心格往对角线下方移一格"开始**，也就是不含中心格/对角线。

### 1.2 两个恒等式

```
严格下三角（i1<i2<...<ik）之和 = 初等对称多项式  e_k(x) = C(S, k)      项数 C(n,k)
完整下三角（i1≤i2≤...≤im）之和 = 完全齐次对称多项式 h_m(x) = C(S+m-1,m)  项数 C(n+m-1,m)
```

两者关系（Pascal 矩阵求逆）：

```
e_K = Σ_{j=1..K} (-1)^(K-j) · C(K-1, j-1) · h_j
例：e_1 = h_1 ;  e_2 = h_2 - h_1 ;  e_3 = h_3 - 2h_2 + h_1
```

**违反指示**（穷举 C=0,1,2 全部 PASS）：

```
Σx ≤ C   违反 ⟺ Σx ≥ C+1   ->  P = e_{C+1}(x) = C(S, C+1)
```

### 1.3 加权推广（MIPLIB 约束系数不为 1 时）

把每个变量按系数 a_j 复制成 a_j 个"单位副本"，取严格 (K) 元子集：

```
e_K^(a)(v) = Σ_{m_j ∈ [0,a_j], Σm_j=K} [ Π_j C(a_j, m_j) ] · Π_j v_j
```

验证例：a=(3,1)、K=3 → `e_3 = v_1 + 3·v_1v_2`（手算一致）。

完整版：`h_m^(a)(v) = Σ_{Σm_j=m} [ Π_j C(a_j+m_j-1, m_j) ] · Π_j v_j`

### 1.4 二次化（扁平化）

Rosenberg gadget（引用度最高的经典归约）：

```
P_cons = v_i·v_j - 2·v_i·w - 2·v_j·w + 3·w     (P_cons = 0 ⟺ w = v_i·v_j)
高次项 c·v_1...v_k  ->  c·w·v_3...v_k + λ·P_cons，递归降到二次
```

相关文献（按引用度/贴合度）：
Rosenberg 1975 → Kolmogorov & Zabih 2004 → Ishikawa 2011 →
Anthony/Boros/Crama/Gruber 2016 (DAM 203:1-12) →
Boros/Crama/Rodríguez-Heck 2020 (JOCO 39:687-707) →
**Dattani & Chau 2019（4 变量函数只用 1 个辅助变量即可"完美"二次化）** →
Verma/Lewis/Kochenberger 2021 (arXiv:2107.11695) →
**Crama/Elloumi/Lambert/Rodríguez-Heck 2025 (JOCO 50:3)（最新，三阶段法）**

## 4. 关键发现

### 4.1 优势区间由 K 决定，分界点约在 K ≈ 3~4

| 实例 | K | 超立方体(strict) 总变量 | 二元松弛 总变量 | 比值 | 胜者 |
|---|---|---|---|---|---|
| sorrell7 | 2 | 2048 | 80896 | **1 : 39.5** | 超立方体 |
| f2000 | 3 | 12500 | 23000 | 1 : 1.84 | 超立方体 |
| circ10-3 | 1~2 | 22140 | 60190 | 1 : 2.7 | 超立方体 |
| ramos3 | 15 | 30618 | **10935** | 2.8 : 1 | **二元松弛** |

**机制**：超立方体的项数是 C(n_row, K)，K 增长时组合数爆炸；
二元松弛的辅助变量数只与右端 C 的对数相关，与 n_row 无关。
所以 **K 小（约束是"至多 K−1 个"这类基数型）时超立方体大胜；K 大时松弛变量赢**。

### 4.2 严格版 vs 完整版：最终结果完全相同

- sorrell7：两者都是 2048 变量 / 39424 耦合
- f2000：两者都是 12500 变量 / 35995 耦合
- 印证了 `e_K = Σ(-1)^(K-j)C(K-1,j-1)h_j` 的等价性

**但完整版有两个硬伤**：
1. **大 K 直接不可用**：ramos3（K=15）2187 行全部跳过（要展开 h_1..h_15，中间项数爆炸）
2. **编码更慢**：circ10-3 用 376.8s vs 严格版 272.0s

### 4.3 标记：**严格下三角（strict）是最好的版本**

理由：
1. 结果与完整版完全相同（都等于 e_K）
2. 项数更少：严格 C(n,K) vs 完整 C(n+K−1,K)
3. 编码更快（circ10-3 快 28%）
4. 大 K 时仍可运行（完整版直接崩溃）

### 4.4 遗留问题

1. **非整数系数行无法编码**：circ10-3 跳过 23360/43070 行（54%）、d20200 跳过 1302/1702 行（76%）。
   需要**兜底机制**：跳过的行回退到松弛变量法，否则 QUBO 不完整、解不可行。
2. **加权推广已推导但未在对比中启用**：当前实现要求行内系数为整数，非整数行直接跳过。
3. **求解质量对比尚未跑**（本轮只做了规模对比）：需要补 SA 求解对比。
