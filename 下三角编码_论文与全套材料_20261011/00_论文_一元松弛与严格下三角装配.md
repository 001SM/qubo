## 摘要

把带**线性不等式约束**的 0/1 组合优化问题送上 QUBO/Ising 求解器，标准做法是「松弛变量 + 平方罚项」，再对高阶项做 Rosenberg 二次化。二次化会引入大量辅助变量（本课题实测约 40 万个），且辅助变量取值约束本身要再靠罚项强制，误差层层叠加。

本文给出一套三段式编码：**一元松弛 → `min_y` 闭式消元 → 严格下三角装配**。核心结论是三条：

1. 一元松弛的松弛块可以被**解析消去**：$\min_y(\sum a_ix_i \pm |y| - C)^2 = \max(0,\mathrm{viol})^2$，因此经典求解器可直接在原变量空间搜索，**一个辅助变量都不需要**；只有需要真正 QUBO 矩阵形式（量子退火 / QAOA）时才把松弛块显式装配出来。
2. 装配时用 $z^2=z$ 把平方项收回线性项、交叉项只在三角一侧存一份，得到闭式 $Q_{kk}=\lambda(a_k^2+2da_k)$、$Q_{kl}=2\lambda a_ka_l\ (k<l)$；这一「三角」结构是 $m$ 维超立方体幂展开取**非降序单形**在 $m=2$ 时的特例。
3. 罚权必须与目标同量级标定。逐行 $\lambda_r$、行归一化、以及 QAP 专用的 $\lambda=\max_{ij}(\sum_k|A_{ik}|\cdot\sum_l|B_{jl}|)$ 规则，是编码能否「精确」的开关——用错规则会让 HUBO 全局最优落在不可行点（本课题首轮 12/17 实例即如此）。

实验覆盖两组题库：MIPLIB 2017 子集（7 个实例，编码层数最复杂）与 QAPLIB 45 个认证最优实例（共 544 个求解任务，0 错误）。编码正确性在可穷举规模上被逐点证实（85/85 项检查通过，高维三件套 26/26 PASS）；在 QAPLIB 上，结构感知的 perm 族求解器 600 s 预算内 **120/136 任务命中认证最优**，加宽到 45 实例后 204/224 命中。同一编码交给通用 HUBO 单点翻转求解器则几乎全军覆没（136 任务中仅 9 个可行、0 命中），说明**编码只决定可行域的形状，搜索邻域结构决定能否走到最优**。

**关键词**：QUBO 编码；一元松弛；严格下三角装配；精确罚函数；HUBO；二次化；模拟退火；QAPLIB；MIPLIB

## 1 引言

### 1.1 问题背景

QUBO / Ising 求解器（量子退火、QAOA、以及各类经典退火与局部搜索）只能处理**无约束**的二次型

$$
\min_{z\in\{0,1\}^N} E(z) = \sum_i Q_{ii}z_i + \sum_{i<j}Q_{ij}z_iz_j .
$$

而实际组合优化问题几乎都带约束。把约束搬进目标的标准手段是**罚函数**：只要 $\lambda$ 足够大，任何不可行解的能量都高于任何可行解，无约束最优解就等于原问题最优解（精确罚函数，Zangwill 1967）。

对线性不等式约束 $\sum_j a_{rj}x_j \le b_r$，教科书流程是三步：引入松弛量 $s$ 把不等式写成等式 → 把 $s$ 二进制化 → 展开平方罚项装配成 QUBO。这三步里，第二步（二进制化方式）与第三步（装配方式）各自都有坑，而第一步引入的松弛变量规模常常被低估。

### 1.2 现有路线的局限

| 路线 | 做法 | 局限 |
|---|---|---|
| 二次化（Rosenberg 1975；Boros et al. 2020） | 高阶项 $x_ix_jx_k$ → 辅助变量 $w$ + 罚项强制 $w=x_ix_j$ | 辅助变量数随阶数线性增长，本课题实测约 **40 万个**；附加的 $w=x_ix_j$ 约束本身仍需罚项，误差叠加 |
| 二元（binary）松弛 | $s=\sum_k 2^k y_k$，只需 $\lceil\log_2(S+1)\rceil$ 个变量 | 系数达 $2^k$ 量级，谱宽大；**没有闭式消元**（最接近的松弛值未必可达） |
| 无松弛（slack-free / 非平衡惩罚，Montanez-Barrera 2024） | 不引入松弛变量，用非平衡惩罚把最优解推向基态 | 只能保证「接近基态」，非严格精确 |
| 一元（unary）松弛（Lucas 2014；Ceselli & Premoli 2023） | $s=\sum_{k=1}^{S} y_k$，系数全为 1 | 变量数随右端**线性**增长（本课题 ramos3 需 8748~78649 个）；表示高度退化 |

**文献现状**：上述每个技术要素在文献中都有对应工作，但没有一篇把「一元松弛 + 严格下三角装配 + `min_y` 闭式消元 + 谱宽归一化」合并为一套完整流程，也没有配套的等价性验证协议。Ceselli & Premoli (2023) 把一元松弛的退化性视为缺点，本文论证其为**无害**（能隙均匀，单比特翻转即可在可行域内移动）。

### 1.3 本文贡献

1. **三要素合并**：一元松弛 → 闭式消元 → 严格下三角装配，给出每条步骤的精确性定理与证明。
2. **经典 / 量子分工判据**：证明一元松弛的松弛块可闭式消去，从而给出明确判据——经典求解器应在 $x$ 空间搜索，只有需要真正 QUBO / Ising 矩阵（上量子硬件）时才引入 $y$ 块，且必须做谱宽归一化。
3. **超立方体视角**：把「下三角」解释为 $m$ 阶幂展开的对称张量取非降序单形，说明为何必须取**完整单形**（含重复下标）而非严格单形，并给出 $e_K$ 精确违反指示。
4. **可复现验证协议**：高维无法穷举时，改用「矩阵-表达式逐点一致性 + 构造性零能 + 解析最小罚项」三件套（26/26 PASS）。
5. **跨题库实验**：MIPLIB（编码层数最复杂）与 QAPLIB 45 实例 × 4 求解器 × 544 任务，全部结果经**独立解析器**复核。

## 2 预备知识

### 2.1 记号

- 原问题变量 $x\in\{0,1\}^n$，目标 $c^\top x$，约束 $m$ 行：$lb_r \le \sum_j a_{rj}x_j \le ub_r$。
- $S$ 为松弛量值域上界；$z$ 为装配后的全变量向量（原变量 + 松弛变量 + 可能的辅助变量）。
- 记 $\mathrm{lhs}_r(x)=\sum_j a_{rj}x_j$。

### 2.2 QUBO 与 Ising 的互转

QUBO 用 $z\in\{0,1\}$，Ising 用 $s\in\{-1,+1\}$，代入 $z_i=(1+s_i)/2$ 得

$$
J_{ij}=\frac{Q_{ij}}{4},\qquad h_i=\frac{Q_{ii}}{2}+\sum_{j\ne i}\frac{Q_{ij}}{4},
\qquad \text{const} \mathrel{+}= \sum_i\frac{Q_{ii}}{2}+\sum_{i<j}\frac{Q_{ij}}{4}.
$$

本文所有推导在 QUBO 形式下给出；经典 SA 直接用 QUBO 更省事，上量子硬件时按上式转换。

### 2.3 精确罚函数

**定理（Zangwill 1967）**：对 $\min\{f(x)\mid g(x)\le 0\}$，存在 $\lambda_0>0$，当 $\lambda\ge\lambda_0$ 时 $f(x)+\lambda\max(0,g(x))^2$ 的无约束最优解即原问题最优解。

本文所有罚项都落于这一框架，差别只在**如何计算违约量**与**如何选 $\lambda$**。

### 2.4 输入标准化（MPS 侧）

解析 MPS 得到 ROWS / COLUMNS / RHS / RANGES / BOUNDS 后，做三步预处理，使方法不限于纯 0/1 问题：

1. **固定变量折叠**：$x_j=v$ → 行右端平移 $lb_r \mathrel{-}= a_{rj}v$，目标常数累加；
2. **整数变量二进制展开**：$x_j = lo_j + \sum_k w_k b_k$，$w=[1,2,4,\dots,2^{bits-2},\,width-(2^{bits-1}-1)]$（末位取余量，保证恰好覆盖 $[0,S]$）；
3. **行归一化**（见 §3.6）。

## 3 编码方法

### 3.1 一元松弛编码

对 $\le$ 型约束引入非负整数松弛量 $s\in[0,S]$，把不等式写成等式，再用一元编码表示 $s$：

$$
s = y_1+y_2+\cdots+y_S,\qquad y_k\in\{0,1\}.
$$

罚项取平方：

$$
P_\le(x,y) = \lambda\Big(\sum_i a_ix_i + \sum_k y_k - C\Big)^2 .
$$

**定理 1（精确性）**：$P_\le$ 的零点集等于原约束的可行集。

*证明*：设 $w=\sum_i a_ix_i$。
- 若 $w\le C$：取 $|y|=C-w\in[0,S]$，则括号内为 0，$P_\le=0$；
- 若 $w>C$：括号内 $= w-C+|y| \ge 1$（因 $|y|\ge 0$ 且 $w-C\ge 1$），故 $P_\le\ge\lambda>0$。

反之 $P_\le=0 \Rightarrow w+|y|=C \Rightarrow w\le C$。$\square$

$\ge$ 型同理，只需把松弛块符号翻负：

$$
P_\ge(x,y)=\lambda\Big(\sum_i a_ix_i - \sum_k y_k - C\Big)^2 .
$$

**关键差异**：展开后 $x$–$y$ 交叉块的下三角系数由 $+2\lambda$ 变为 $-2\lambda$。这正是「常量与超立方体相减」的含义。等价地，取补变量 $z_i=1-x_i$ 可把 $\ge C$ 转为 $\sum z \le n-C$（视角 B），两种视角罚项逐点相同（已数值验证）。

### 3.2 一元 vs 二元松弛

| 维度 | 一元（unary） | 二元（binary） |
|---|---|---|
| 辅助变量数 | $S$（线性） | $\lceil\log_2(S+1)\rceil$（对数） |
| 二次项系数量级 | 小（$\sim 1$） | 大（$2^k$） |
| 表示退化 | 严重（$s=v$ 有 $\binom{S}{v}$ 种表示） | 无 |
| 数值稳定性 | 好 | 差（需精心选 $\lambda$） |
| **闭式消元** | **有**（定理 2） | **无** |
| 实测（ramos3） | 需 7.9 万个辅助变量 → 不可行 | 需 8748 个 → 可用 |

**退化性无害的论证**：$s=v$ 的 $\binom{S}{v}$ 种表示意味着零能态多，但单比特翻转恰好把 $s$ 改变 1，能隙恒为 $1\cdot\lambda$ —— 可行域内部的移动代价均匀，SA 不会卡在某个「表示」上；且全部冗余态映射到同一个 $x$，最终测量/取值不受影响。

### 3.3 `min_y` 闭式消元（本文核心）

**定理 2**：对一元松弛，松弛块可被解析消去：

$$
\min_{y\in\{0,1\}^S}\Big(\sum_i a_ix_i \pm |y| - C\Big)^2 = \max\big(0,\ \mathrm{viol}(x)\big)^2 .
$$

*证明*：记 $u=\sum_i a_ix_i - C$（$\le$ 型）。由于 $|y|$ 可取遍 $[0,S]$ 中每个整数（一元编码的完备性），目标等价于 $\min_{v\in[0,S]\cap\mathbb{Z}}(u+v)^2$。若 $u\ge 0$ 取 $v=0$ 得 $u^2$；若 $u<0$ 且 $-u\le S$，取 $v=-u$ 得 0；若 $-u>S$，取 $v=S$ 得 $(u+S)^2$。写成统一形式即 $\max(0,\mathrm{viol})^2$。$\ge$ 型对称。$\square$

这条性质**只有一元编码有**：二元编码的 $s=\sum 2^ky_k$ 虽然也能覆盖 $[0,S]$，但反过来「给定 $u$ 求最接近的可达 $s$」依赖具体权重分布，不存在这样干净的闭式。

双向违约合起来就得到求解器实际使用的能量函数（附录 A.6.1）：

$$
\mathrm{viol}_r(x) = \max(0,\ \mathrm{lhs}_r-ub_r) + \max(0,\ lb_r-\mathrm{lhs}_r),\qquad
E(x) = c^\top x + \sum_r \lambda_r\,\mathrm{viol}_r(x)^2 .
$$

**推论（经典 / 量子分工判据）**：经典求解器（SA / 禁忌 / 局部搜索 / ILS）应在 $x$ 空间按上式搜索，松弛块整体不存在；只有需要真正的 QUBO / Ising 矩阵（量子退火、QAOA、D-Wave）时，才按 §3.4 把 $y$ 块显式装配出来。这一条直接决定了 §5.2 中「朴素 SA 直接退火完整 QUBO」与「$x$ 空间 SA + 解析罚」的 39% vs 0% gap 差距。

### 3.4 严格下三角装配

需要显式矩阵时，对单条约束（系数向量 $a$，常数 $d$）展开平方：

$$
\lambda\Big(\sum_i a_iz_i + d\Big)^2
= \lambda\Big[\underbrace{\sum_i a_i^2 z_i^2}_{\text{对角}} + \underbrace{2\sum_{i<j}a_ia_jz_iz_j}_{\text{交叉}} + \underbrace{2d\sum_i a_iz_i}_{\text{线性}} + d^2\Big].
$$

利用 $z\in\{0,1\}\Rightarrow z^2=z$，平方项退回线性项，得到装配公式：

$$
\boxed{\ Q_{kk} \mathrel{+}= \lambda\big(a_k^2 + 2da_k\big),\qquad
Q_{kl} \mathrel{+}= 2\lambda a_ka_l\ (k<l),\qquad
\mathrm{const} \mathrel{+}= \lambda d^2\ }
$$

**为什么必须只在三角一侧存**：交叉项本质无向（$z_iz_j=z_jz_i$）。若两侧都存，能量 $\sum_i\sum_j Q_{ij}z_iz_j$ 会把每对算两次，等于把 $\lambda$ 隐式放大一倍——这是实现中最常见的错误。两种写法等价，因为 $z^\top Qz = \sum_iQ_{ii}z_i + 2\sum_{i<j}Q_{ij}z_iz_j$。

对 $\sum x \le C$ 这种计数约束，上式简化为极整洁的形态：

$$
P_\le = (1-2C)\sum_k z_k + 2\sum_{k<l}z_kz_l + C^2,
$$

即：线性项全为 $1-2C$，严格下三角全为 $+2$，常数 $C^2$（可省）。$\ge$ 型只需把 $y$ 块线性项换成 $1+2C$、$x$–$y$ 交叉块换成 $-2$。

### 3.5 超立方体视角：非降序单形

「下三角」不是 $m=2$ 的巧合。把幂展开看作对称张量：

$$
\Big(\sum_{i\in\mathcal S}a_ix_i\Big)^m = \sum_{i_1,\dots,i_m\in\mathcal S} a_{i_1}\cdots a_{i_m}\,x_{i_1}\cdots x_{i_m},
$$

右端是 $m$ 阶张量（$m$ 维超立方体，边长 $|\mathcal S|$，共 $|\mathcal S|^m$ 个**有序**项）。乘法可交换，故每项只取决于下标**多重集**；取非降序代表元 $i_1\le i_2\le\cdots\le i_m$ 去重，项数

$$
|\mathcal S|^m \ \longrightarrow\ \binom{|\mathcal S|+m-1}{m}.
$$

**这就是「超下三角」—— 一个完整单形，不是严格单形**。重复下标项必须计入，因为它们在 $x^k=x$ 下降阶后贡献到低阶层：

| 不同下标个数 $k$ | 例子 | 降阶后 | 落在哪一层 |
|---|---|---|---|
| 1 | $a_3a_3a_3$ | $a_3^3x_3 \to a_3x_3$ | 线性项 |
| 2 | $a_1a_1a_2$ | $a_1^2a_2\,x_1x_2$ | 二次项 |
| 3 | $a_1a_2a_3$ | $6a_1a_2a_3\,x_1x_2x_3$ | **真三次项** |

若只取严格单形，$k=1,2$ 层的系数会缺失，整个多项式就错了——这与「忘记 $z^2=z$」是同一件事。$m=2$ 时非降序单形 $=\{i=j\text{ 的 }n\text{ 项}\}\cup\{i<j\text{ 的 }\binom n2\text{ 项}\}$，与 §3.4 完全吻合。

### 3.6 $e_K$ 精确违反指示与混合策略

对计数型约束，$e_K$ 给出**精确**的违反指示（无松弛变量、无编码误差）：

$$
e_K(x)=\sum_{i_1<\cdots<i_K}x_{i_1}\cdots x_{i_K} = \binom{S}{K},\qquad S=\sum_i x_i .
$$

| 约束型 | 违反条件 | 精确指示 | 最高阶 |
|---|---|---|---|
| $\le$ 型 $\sum x\le C$ | $S\ge C+1$ | $e_{C+1}(x)=\binom{S}{C+1}$：$S\le C$ 时恒 0，$S\ge C+1$ 时严格正且单调增 | $C+1$ 元 |
| $\ge$ 型 $\sum x\ge C$ | $S\le C-1$ | 取补 $y=1-x$ 转 $\le$ 型 | $C-1$ 元 |

**注意**：常量 $C$ 直接决定幂展开阶数，因此 $C$ 大时项数 $\binom{n}{K}$ 爆炸。

工程上采用 **strict 优先 + 松弛兜底** 的混合策略（附录 A.2 / A.3）：

1. 每侧的 $\le$ / $\ge$ 先尝试 strict：canonical 化（GCD 归一化 + 补变量替换）后用 $e_K$ 直构；
2. 任一环节失败（系数非整数 / 右端非整数 / $K$ 超限 / 项数超 cap）→ 该侧**回退**到松弛编码（一元或二元 + 平方罚项，与 §3.1 完全同构）。

这样保证**每行每侧必有罚项，不再跳行**。QAP 与 MIPLIB 共用这套哲学。

### 3.7 罚权 $\lambda$ 的标定（最容易出错的一环）

两条下界（最小化问题）：

$$
\lambda > \frac{\Delta_{\max}\text{obj}}{\mathrm{viol}_{\min}^2},\qquad
\lambda\ \text{与温度}\ T\ \text{必须同量级}.
$$

**行归一化**（控制谱宽 $O(C^2)$）：

$$
s_r=\max\big(\max_j|a_{rj}|,\ |lb_r|,\ |ub_r|,\ 1\big),\qquad a_{rj}\leftarrow a_{rj}/s_r .
$$

**MIPLIB 逐行罚权**：

$$
\mathrm{viol\_unit}_r = \min_j |a_{rj}|,\qquad
\lambda_r = \min\Big(\frac{2\,c_{\max}}{\mathrm{viol\_unit}_r^2},\ 10^4 c_{\max}\Big),\quad c_{\max}=\max_j|c_j| .
$$

**QAP 专用规则**（与 MIPLIB 不同，踩过坑）：

$$
\lambda = \max_{i,j}\Big(\sum_k|A_{ik}|\cdot\sum_l|B_{jl}|\Big).
$$

*推导*：目标对 $x_{ij}$ 单调（系数非负），删掉「设施 $i\to$ 位置 $j$」这一个赋值，目标损失
$\Delta\mathrm{obj}=\sum_{k,l}A_{ik}B_{jl}x_{kl}\le(\sum_kA_{ik})(\sum_lB_{jl})$；同时设施行 $i$、位置列 $j$ 各违 1 行 $\ge1$ 约束，罚增 $2\lambda$。故只要 $2\lambda>\Delta\mathrm{obj}_{\max}$，HUBO 全局最优就不可能落在「丢 1 格」的点上。另需 $2n\lambda>\mathrm{OPT}$ 压住全零点。用 MIPLIB 的 $2c_{\max}$ 会少一个 $n$ 因子——这正是首轮 **12/17 实例 HUBO 全局最优不可行**的原因。

**λ 的两头都是坑**：$\lambda$ 过小 → 约束不被满足；$\lambda$ 过大 → 所有移动被拒绝，搜索**冻结**（实测 $\lambda=1000\,c_{\max}$ 时 SA 在 60 s 内接受 0 次移动）。ramos3 的 941% gap 即「罚项淹没目标」的典型：能量 $-59243$ 几乎全由罚项构成，拿到可行解后目标梯度被淹没。

### 3.8 QAP → HUBO 编码

QAP：$\min_\pi \sum_{i,k}A_{ik}B_{\pi(i)\pi(k)}$。二进制化 $x_{ij}=1\iff$ 设施 $i$ 放位置 $j$（$n^2$ 个变量）：

- **目标**：$\sum_{i,k,j,l}A_{ik}B_{jl}x_{ij}x_{kl}$（二次；互斥对 $i=k$ 或 $j=l$ 在可行点恒为 0，直接跳过以省项数）；
- **one-hot 约束**（每设施一行、每位置一行，共 $2n$ 行 $\sum x=1$）：
  - $\le 1$ 侧：strict $e_2=\lambda\sum_{a<b}x_ax_b$（二次、精确指示、**无松弛**）；
  - $\ge 1$ 侧：松弛兜底 $\lambda(\sum x - \sum_b 2^b s_b - 1)^2$。

「至少选一」在 $n\ge3$ 时不存在二次精确罚项（Anthony et al. 2016 给出辅助变量下界 $\Omega(\sqrt n)$），必须引入松弛或 $n$ 次多项式——这是 $\ge1$ 侧只能走兜底的理论原因。

**起跑自检（preflight）**：以认证最优排列为基准，逐点验证「全零点 / 丢 1 格 / 随机扰动点」能量都不低于 OPT，不通过则拒绝起跑。这条自检把「λ 标定错了」从**事后才发现**变成**跑前拦下**。

## 4 求解算法

### 4.1 两阶段多周期回热 SA（MIPLIB 侧）

```
sa_solve(inst, budget):
  # 阶段1：多初值竞选（45% 预算）
  inits = [官方解?, CBC解?, LP取整, LP随机化舍入×3, 全1, 全0, 随机]
  for init in inits:
      if greedy_repair(init) 成功: 得到可行解; break
      else: walksat(init)
      # 全程跟踪"最好违约量"的解，供阶段2回退

  # 阶段2：多周期回热 SA（55% 预算）
  lam_scale = 1 ; stall = 0 ; T0_full = cmax ; Tmin = 0.01·cmax
  while 未超时:
      lamv = lam_scale · λ_row                      # 逐行罚权
      T0 = min( T0_full·(1 + 0.5·stall), 4·T0_full ) # 停滞越久越热，但封顶
      if 有可行解 and stall ≥ 1: x ← best_x          # 从最优解重启
          if stall ≥ 3: 随机翻转 n/(20·stall) 个变量  # 扰动保持多样性
      sa_cycle(T0 → Tmin, 200k 步):
          以 0.35 概率做交换移动（1→0 与 0→1 同时翻转），否则单比特翻转
          ΔE = Δobj + Σ_{受影响行} λ_r·Δviol_r²      # 列式 CSR，O(deg) 增量
          接受 if ΔE ≤ 0 or rand < exp(−ΔE/T)
      if 不可行:
          x ← best_x 或 best_repair_x                # 先回退，别从散点硬修
          有界修复：greedy_repair / walksat，限时 ≤ min(60s, 8%·预算)
          仍不可行 → lam_scale ← lam_scale · 10      # 加压强
      else:
          每周期抛光 polish(best_x)                  # 可行域内局部最优化
  收尾：再抛光一次
```

**交换移动是必需的**：紧约束下（如 one-hot 行）单比特翻转几乎必被拒，1↔0 同时翻转是唯一可行的大范围移动。

### 4.2 可行化算子

- **`greedy_repair`**：按违约从大到小遍历违约行，全支撑/抽样（$\le$64 候选）扫描选使总违约下降最多的变量翻转，重复至无改善。
- **`walksat`**：维护违约行集合（$O(1)$ 增删/抽样）；随机取违约行 → 以 $1-\text{noise}$ 取最优翻转、$\text{noise}$ 取随机翻转；总违约下降则 $\text{noise}\leftarrow\max(0.15,\text{noise}-0.05)$，停滞 4000 步则 $\text{noise}\leftarrow\min(0.7,\text{noise}+0.1)$，停滞 20000 步则从 best_x 扰动 $n/25$ 个变量重启。
- **`polish`**：只接受「既降目标又保持可行」的移动（单翻转 + 行内交换）。

### 4.3 经典求解器族（QAP / HUBO 侧）

四个求解器、两种邻域：

| 族 | 初始化 | 邻域 | 说明 |
|---|---|---|---|
| `perm` | 可行初始化 | **swap**（保可行性） | 结构感知，始终在置换空间内 |
| `hubo` | 随机起步 | 单点翻转 | 通用 HUBO，不利用结构 |

求解器：greedy（最速下降）、sa（Metropolis + 几何冷却 + 重启）、tabu（禁忌表）、ils（迭代局部搜索 + 扰动）。

### 4.4 独立校验协议

```
report(x):
    vals = to_raw(x)        # 固定变量折叠回补 + 整数展开 x_j = lo_j + Σ w_k b_k
    write_sol(vals)         # MIPLIB .sol 格式
    verify_sol(mps, sol):   # 完全独立的解析器 + 独立复算（不复用求解器任何代码）
        逐行重算 lhs = Σ a_rj x_j（缺失变量按 0），检查 [lb_r, ub_r]（含 RANGES）
        检查变量界 → 越界变量数；独立复算目标并与声明值比对
    if 违反行数 > 0: 该解不是解，目标值无意义，不报告 gap
```

**这条是铁律**：不可行解可以刷出任意「更好」的目标值（本实验 d20200 的 $-90\%$、t1722 的 $-90.3\%$ 都是这种假象）。**先看违反行数，再看 gap**。

**逐实例解读**：

- **d20200 / ex1010-pi**：strict 侧为 0 或 1，退化为纯惩罚法。

**三种可区分的失败机制**（不能混为一谈）：

1. **罚项量级失衡**（ramos3）：可行但目标被罚项淹没；
2. **预算/轮数不足**（t1722 只跑 1 轮、circ10-3 只跑 5 轮）：大 QUBO 单轮投票就吃掉全部预算；
3. **gap 口径陷阱**（d20200 $-90\%$、ex1010-pi $2937\%$）：不可行解的 gap 无意义。

### 5.4 HUBO（不二次化）vs 二次化 QUBO 的效率对比

40 个子问题（$n=9\sim16$，HUBO 变量 = 原变量，**无辅助变量**），同预算 3 s：

| 方法 | 类型 | 达到精确最优 | 平均耗时 | 说明 |
|---|---|---|---|---|
| CBC（直接解原子问题） | 精确 | 40/40 | ≈0.01 s | 小规模无敌 |
| **HUBO + 经典单点 SA** | 启发式 | **40/40** | **0.91 s** | 高阶多项式上朴素 SA + 4 重启 |
| HUBO + 分块穷举 | 精确 | 40/40 | 0.001~3.3 s | 项数 $2^K$ 增长：$K=15$ 时 3.3 s |
| 我们算法（迭代消元投票 SA，QUBO 路线，3 s） | 启发式 | 22/40 | 2.80 s | 失败集中在 d20200(8/8)、circ10-3 s1、f2000 |
| 我们算法（30 s 预算重跑） | 启发式 | 26/40 | 7.9 s | 加预算仍失败，排除预算不足 |

**结构对比**：

| 维度 | HUBO（不二次化） | QUBO（Rosenberg 二次化） |
|---|---|---|
| 变量数 | $n$ + 松弛（**无辅助**） | $n$ + 松弛 + $\sum(\text{阶数}-1)$ 个辅助 |
| 代价 | 项数按 $2^K$ 增长（d20200 $K=15$ 时 32767 项；全实例超 20 万项上限） | 耦合数受预算控制 |
| 求解器生态 | 需支持高阶 $\Delta E$ 的 SA / 局部搜索 | 现有 QuboGraph / 迭代消元直接可用 |

**我们算法失败机制定位（重要发现）**：以 d20200#mv10#s1 为例（行结构 $\sum x=1$，one-hot）——编码无错（穷举全局最优 $E^*=5$ 等于 CBC 最优，20 次独立单跑 SA 都能找到可行解），**失败在投票环节**：该 QUBO 有 10 个对称最优（恰好一个变量 $=1$），每次 SA 返回一个单 1 解，逐坐标统计每变量只有 ~10% 轮次取 1 → **多数票把所有变量都投成 0**，拼出不可行全零解。one-hot（分配型）结构与坐标级多数投票**系统性冲突**。修复方向（未实施）：死锁/超时兜底时改用「取能量最低的单轮 SA 解」或按轮次能量加权投票。

## 6 结论

### 6.1 已确立的结论

1. **编码正确性是可靠的**。一元松弛 + 严格下三角装配在可穷举规模上被逐点证实：低维穷举逐项通过（并查出早期实现的 2 个编码 bug，修正后回归 8/8 PASS）、高维三件套 26/26、HUBO 罚项 70/70 项检查通过。$\le$ / $\ge$ 双向、加权、取补等价、$m=C-1$ 边界情形均无误。
2. **闭式消元是这套方法相对二次化的核心优势**。$\min_y$ 闭式让经典求解器完全不需要松弛块（省掉约 40 万辅助变量），并在 $n=60$ 背包上把 gap 从 39% 拉到 0%。
3. **strict $e_K$ 覆盖率决定求解上限**。strict 侧占比 100%/99.9% 的 sorrell7、f2000 得到与问题近乎同构的 QUBO（gap 9.7%/16.7%）；strict 侧为 0 的大 $K$ 实例退化为纯惩罚法，多数连可行解都拿不到。
4. **λ 标定是开关，不是调参**。QAP 侧 $\lambda=\max_{ij}(\sum_k|A_{ik}|\cdot\sum_l|B_{jl}|)$ 与 MIPLIB 的 $2c_{\max}/\mathrm{viol\_unit}^2$ 是两套不同规则；用错会让 HUBO 全局最优落在不可行点。跑前 preflight 自检把这类错误从事后发现变成跑前拦下。
5. **邻域结构比编码更决定成败**。QAPLIB 上 perm（swap）88.2% 命中 vs hubo（单点翻转）0% 命中，是本文最强烈的对照。
6. **热启动是必要组件**。冷启动 180 s 只有 1/7 实例可行；60 s CBC 起点让 ex1010-pi 从 2937% 降到 5.15%。ILS 是 1248 任务里最稳的求解器（96% 命中，平均 gap +6.83%）。

### 6.2 明确的局限（诚实说明）

- **大规模 MIPLIB 上仍不能用**：7 个实例里只有 f2000（9.72%）称得上可用，ramos3/d20200/t1722/ex1010-pi 要么不可行、要么目标被罚项淹没。症结在兜底侧的罚权标定（$\lambda_r$）与大 $K$ 行的项数爆炸。
- **坐标级多数投票与 one-hot 结构系统性冲突**：d20200 8/8 全败已定位到机制（10 个对称最优被多数票投成全零），修复方向明确（best-of-runs / 能量加权投票）但**未实施**。
- **项数随 $K$ 指数增长**是 HUBO 路线的硬约束（$2^K$），必须配合项数预算与兜底。
- **未与 SOTA 求解器对比**：本报告只对照经典求解器（CBC / SA / ILS / tabu / greedy）与官方认证值，没有 BnB / 商业求解器的长时限对比。

### 6.3 下一步

1. 修投票兜底策略（best-of-runs），重跑 d20200 组；
2. 重新标定兜底侧 $\lambda_r$ 后重跑 QAP（标定好之前重跑没有意义）；
3. 对高 $K$ 行用 HUBO 混合求解（高阶项直接进 SA，不二次化），避开 aux 预算引起的兜底误差；
4. 补 SOTA 对比，把「效率优势」从「相对经典启发式」推进到「相对精确求解器」。

### A.1 一元松弛 / 二元松弛 + 严格下三角装配 → QUBO

源码：`tests\miplib_qubo\qubo_build.py`

```python
"""
MIPLIB 实例 → 完整 QUBO/Ising 模型（一元松弛 / 二元松弛 + λ 罚项装配）
=====================================================================
流程：
  1) 解析 MPS（复用 miplib_sa_test.parse_mps / Instance：固定变量折叠、整数展开、
     行归一化，得到全 0/1 变量空间）
  2) 每条约束加松弛变量：
       L 行 (lhs ≤ ub):  lhs + s = ub,  s ∈ [0, S],  S = ub − Σ_j min(0, a_rj)
       G 行 (lhs ≥ lb):  lhs − s = lb,  s ∈ [0, S],  S = Σ_j max(0, a_rj) − lb
       E 行:              lhs = rhs（无松弛）
       R 行:              拆成两条不等式
     松弛编码二选一：
       一元(unary):  s = Σ_{k=1..S} y_k                    （S 个辅助变量，系数全 1）
       二元(binary): s = Σ_k w_k y_k,  w=[1,2,4,...,余量]   （⌈log2(S+1)⌉ 个）
  3) 罚项装配（下三角/上三角规则，利用 z² = z）：
       λ(Σ a_i z_i + d)²  =  λ[ Σ_i a_i² z_i + 2Σ_{i<j} a_i a_j z_i z_j
                               + 2d Σ_i a_i z_i + d² ]
       → 线性项 h_i += λ(a_i² + 2 d a_i)
       → 上三角 Q_ij += 2λ a_i a_j  (i<j)
       → 常数项  += λ d²
  4) 输出 (h, Q, const)，交给迭代消元全局退火（sa_iterative_v4/v5）求解

罚权：λ_r = 2·max(1,cmax) / viol_unit_r²，viol_unit_r = min(min_j|a_rj|, 1)
      （只需 > Δmax_obj/viol_unit²；过大反而冻结搜索）
"""
from __future__ import annotations

import os
import sys

import numpy as np

sys.path.insert(0, r"D:\玻色\下三角算法\tests\miplib_hard")
import miplib_sa_test as core

def build_qubo(inst: core.Instance, slack: str = "unary",
               lam_scale: float = 1.0, lam_cap_mult: float = 1e4):
    n_orig = inst.n
    cmax = max(1.0, float(inst.cmax))
    const = float(inst.obj_const)
    ri, ci, av = inst.ri_r, inst.ci_r, inst.av_r
    row_slice = np.searchsorted(ri, np.arange(inst.m))
    row_end = np.searchsorted(ri, np.arange(inst.m), side="right")

    slack_rows = []
    nxt = n_orig
    n_slack = 0
    for r in range(inst.m):
        s, e = row_slice[r], row_end[r]
        if e <= s:
            continue
        cols = ci[s:e]
        vals = av[s:e]
        lo, hi = inst.lb[r], inst.ub[r]
        lo_f, hi_f = np.isfinite(lo), np.isfinite(hi)
        viol_unit = min(float(np.abs(vals).min()), 1.0)
        lam = min(lam_scale * 2.0 * cmax / max(viol_unit ** 2, 1e-18),
                  lam_cap_mult * cmax)

        def add_slack(bound, sign):
            nonlocal nxt, n_slack
            coefs = [(int(c), float(v)) for c, v in zip(cols, vals)]
            if sign > 0:
                S = bound - float(np.minimum(vals, 0).sum())
            else:
                S = float(np.maximum(vals, 0).sum()) - bound
            S = int(np.floor(S + 1e-9))
            if S < 0:
                return None
            if slack == "unary":
                weights = [1] * S
            else:
                if S == 0:
                    weights = []
                else:
                    bits = max(1, int(np.ceil(np.log2(S + 1))))
                    weights = [2 ** k for k in range(bits - 1)]
                    weights.append(S - (2 ** (bits - 1) - 1))
            for w in weights:
                coefs.append((nxt, float(sign * w)))
                nxt += 1
                n_slack += 1
            return coefs, -float(bound)

        if lo_f and hi_f and abs(hi - lo) < 1e-12:
            coefs = [(int(c), float(v)) for c, v in zip(cols, vals)]
            slack_rows.append((r, coefs, -float(hi), lam))
        else:
            if hi_f:
                got = add_slack(hi, +1)
                if got:
                    slack_rows.append((r, got[0], got[1], lam))
            if lo_f:
                got = add_slack(lo, -1)
                if got:
                    slack_rows.append((r, got[0], got[1], lam))

    n_total = nxt
    h = np.zeros(n_total, dtype=np.float64)
    h[:n_orig] = inst.c
    from scipy.sparse import coo_matrix
    rows_i, cols_j, vals_q = [], [], []
    for _, coefs, d, lam in slack_rows:
        idx = np.array([c[0] for c in coefs], dtype=np.int64)
        aa = np.array([c[1] for c in coefs], dtype=np.float64)
        h[idx] += lam * (aa * aa + 2.0 * d * aa)
        k = idx.size
        if k < 2:
            const += lam * d * d
            continue
        ii, jj = np.triu_indices(k, k=1)
        pi, pj = idx[ii], idx[jj]
        lo_ = np.minimum(pi, pj)
        hi_ = np.maximum(pi, pj)
        rows_i.append(lo_)
        cols_j.append(hi_)
        vals_q.append(2.0 * lam * aa[ii] * aa[jj])
        const += lam * d * d
    if rows_i:
        ri_cat = np.concatenate(rows_i)
        ci_cat = np.concatenate(cols_j)
        vv_cat = np.concatenate(vals_q)
        Q = coo_matrix((vv_cat, (ri_cat, ci_cat)),
                       shape=(n_total, n_total)).tocsr()
        Q.sum_duplicates()
    else:
        Q = coo_matrix((n_total, n_total)).tocsr()
    return dict(h=h, Q=Q, const=const, n_orig=n_orig, n_total=n_total,
                n_slack=n_slack, n_cons=len(slack_rows), slack=slack,
                nnz=int(Q.nnz))

def main():
    import argparse
    ap = argparse.ArgumentParser()
    ap.add_argument("--dir", default=r"D:\玻色\下三角算法\tests\miplib_qubo")
    ap.add_argument("--instances", required=True)
    ap.add_argument("--slack", default="both", choices=["unary", "binary", "both"])
    ap.add_argument("--save", default="")
    a = ap.parse_args()
    for name in [x.strip() for x in a.instances.split(",") if x.strip()]:
        inst = core.Instance(name, os.path.join(a.dir, name + ".mps"))
        for mode in (["unary", "binary"] if a.slack == "both" else [a.slack]):
            q = build_qubo(inst, slack=mode)
            print("%-16s %-6s 原变量=%5d 松弛变量=%7d 约束=%6d → QUBO 规模=%6d "
                  "非零耦合=%8d" % (name, mode, q["n_orig"], q["n_slack"],
                                    q["n_cons"], q["n_total"], q["nnz"]))
            if a.save:
                np.savez_compressed(
                    os.path.join(a.dir, "%s_%s.npz" % (name, mode)),
                    h=q["h"], data=q["Q"].data, indices=q["Q"].indices,
                    indptr=q["Q"].indptr, shape=q["Q"].shape,
                    const=q["const"], n_orig=q["n_orig"], n_slack=q["n_slack"])

if __name__ == "__main__":
    main()
```

```python
"""

"""

def _canon_side(vals, bound, is_le, use_gcd=True):
    vals = np.asarray(vals, dtype=float)
    nz = np.abs(vals) > 1e-9
    if not nz.any():
        return []
    wa = np.abs(vals[nz])
    if np.max(np.abs(wa - np.round(wa))) > 1e-6:
        return None
    if abs(bound - round(bound)) > 1e-6:
        return None
    w = np.round(wa).astype(np.int64)
    if (w <= 0).any():
        return None
    sgn = np.where(vals[nz] > 0, 1, -1).astype(np.int8)
    B = int(round(bound))
    S = int(w.sum())
    g = 1
    if use_gcd:
        for x in w.tolist():
            g = gcd(g, x)
            if g == 1:
                break
    if is_le:
        if B < 0:
            return None
        K = B // g + 1
        return (w // g, sgn.copy(), K)
    else:
        if S - B + 1 <= 0:
            return None
        Rq = -((-B) // g)
        K = S // g - Rq + 1
        if K <= 0:
            return None
        return (w // g, (-sgn).astype(np.int8), K)

def _count_monomials(w, K, cap=100_000):
    K = int(K)
    if K <= 0:
        return 0
    dp = [0] * (K + 1)
    dp[0] = 1
    for wj in w.tolist():
        wj = int(wj)
        ndp = [0] * (K + 1)
        pref = 0
        for k in range(K + 1):
            pref += dp[k]
            lo = k - wj - 1
            if lo >= 0:
                pref -= dp[lo]
            ndp[k] = pref if pref <= cap else cap + 1
        dp = ndp
        if min(dp) > cap:
            return None
    c = dp[K]
    return None if c > cap else c

def _quadratize_fast(terms, lam_quad, n_base):
    pending = {}

    def bump(d, key, val):
        d[key] = d.get(key, 0.0) + val

    in_heap = set()
    heap = []
    for k, v in terms.items():
        if abs(v) > 1e-12:
            bump(pending, k, v)
            if len(k) > 2:
                heappush(heap, (-len(k), k))
                in_heap.add(k)
    extra = {}
    aux_defs = {}
    n_aux = 0
    while heap:
        _, key = heappop(heap)
        in_heap.discard(key)
        c = pending.pop(key, None)
        if c is None or abs(c) <= 1e-12:
            continue
        n1, n2 = key[0], key[1]
        rest = key[2:]
        wnode = (n_base + n_aux, 1)
        aux_defs[n_aux] = (n1, n2)
        n_aux += 1
        nk = tuple(sorted((wnode,) + rest))
        bump(pending, nk, c)
        if len(nk) > 2 and nk not in in_heap:
            heappush(heap, (-len(nk), nk))
            in_heap.add(nk)
        bump(extra, tuple(sorted((n1, n2))), lam_quad)
        bump(extra, tuple(sorted((n1, wnode))), -2.0 * lam_quad)
        bump(extra, tuple(sorted((n2, wnode))), -2.0 * lam_quad)
        bump(extra, (wnode,), 3.0 * lam_quad)
    for k, v in extra.items():
        bump(pending, k, v)
    return ({k: v for k, v in pending.items() if abs(v) > 1e-12}, n_aux,
            aux_defs)

def _slack_weights(S, slack):
    if S == 0:
        return []
    if slack == "unary":
        return [1] * S
    bits = max(1, int(np.ceil(np.log2(S + 1))))
    ws = [2 ** k for k in range(bits - 1)]
    ws.append(S - (2 ** (bits - 1) - 1))
    return ws

def build_hybrid_qubo(inst, mode="strict", slack="binary", lam_scale=1.0,
                      cap_terms=2_000_000, K_full_cap=12, use_gcd=True,
                      fallback=True, node_cap=1_000_000, K_strict_cap=25,
                      terms_side_cap=100, aux_side_cap=8, progress=None):
    n_orig = inst.n
    cmax = max(1.0, float(inst.cmax))
    lam_con = lam_scale * 2.0 * cmax
    lam_quad = lam_scale * 4.0 * cmax

    use_raw = hasattr(inst, "av_orig")
    if use_raw:
        order = np.lexsort((inst.ci, inst.ri))
        ri_, ci_, av_ = inst.ri[order], inst.ci[order], inst.av_orig[order]
        sc_all = inst.scale
        lb_, ub_ = inst.lb * sc_all, inst.ub * sc_all
    else:
        ri_, ci_, av_ = inst.ri_r, inst.ci_r, inst.av_r
        sc_all = np.ones(inst.m)
        lb_, ub_ = inst.lb, inst.ub
    rs = np.searchsorted(ri_, np.arange(inst.m))
    re_ = np.searchsorted(ri_, np.arange(inst.m), side="right")
    t_build = time.time()

    strict_terms = {}
    slack_rows = []
    n_slack = 0
    n_strict = n_fb = n_skip = 0
    n_ovf = 0
    Ks = []
    NODE_CAP = node_cap
    nxt = n_orig

    for r in range(inst.m):
        if progress and r and r % 5000 == 0:
            progress(f"    行 {r}/{inst.m}  strict={n_strict} 兜底={n_fb} "
                     f"ovf={n_ovf} 用时{time.time()-t_build:.0f}s")
        s, e = rs[r], re_[r]
        if e <= s:
            continue
        cols = ci_[s:e]
        vals = av_[s:e]
        nz = np.abs(vals) > 1e-9
        cols_nz = cols[nz]
        sc = float(sc_all[r])
        lo, hi = lb_[r], ub_[r]
        negsum = float(-vals[vals < -1e-9].sum())
        eq = np.isfinite(lo) and np.isfinite(hi) and abs(hi - lo) < 1e-12
        if eq:
            sides = [("le", hi + negsum), ("ge", lo + negsum)]
        else:
            sides = []
            if np.isfinite(hi):
                sides.append(("le", hi + negsum))
            if np.isfinite(lo):
                sides.append(("ge", lo + negsum))

        a_n = vals / sc
        au = np.abs(a_n)
        vu = float(au.min()) if au.size else 1.0
        lam_r = min(lam_scale * 2.0 * cmax / max(vu * vu, 1e-18),
                    1e4 * cmax)

        for typ, bound in sides:
            handled = False
            cr = _canon_side(vals, bound, is_le=(typ == "le"),
                             use_gcd=use_gcd)
            if cr is not None and len(cr) == 0:
                handled = True
            elif cr:
                w, sgn, K = cr
                kcap = K_full_cap if mode == "full" else K_strict_cap
                ok_k = K <= kcap
                t = None
                if ok_k:
                    if mode == "strict":
                        if _count_monomials(w, K, terms_side_cap) is None:
                            n_ovf += 1
                        else:
                            t = build_e_K(w, K, terms_side_cap,
                                          max_nodes=NODE_CAP)
                            if t is None:
                                n_ovf += 1
                    else:
                        t = _e_K_from_h(w, K, cap_terms)
                        if t is None:
                            n_ovf += 1
                    if t is not None:
                        if sum(len(k) - 1 for k in t) > aux_side_cap:
                            n_ovf += 1
                        else:
                            for key, coef in t.items():
                                node = tuple(sorted(
                                    (int(cols_nz[j]), int(sgn[j]))
                                    for j in key))
                                strict_terms[node] = \
                                    strict_terms.get(node, 0.0) + lam_con * coef
                            n_strict += 1
                            Ks.append(K)
                            handled = True
                else:
                    n_ovf += 1
            if handled or not fallback:
                continue

            lo_n, hi_n = lo / sc, hi / sc
            if eq:
                ids = cols.astype(np.int64)
                slack_rows.append((lam_r, ids, a_n.copy(), -float(hi_n)))
            elif typ == "le":
                S = int(np.floor(hi_n - float(np.minimum(a_n, 0).sum()) + 1e-9))
                if S < 0:
                    n_skip += 1
                    continue
                ws = _slack_weights(S, slack)
                ids = np.concatenate([cols.astype(np.int64),
                                      np.arange(nxt, nxt + len(ws),
                                                dtype=np.int64)])
                a_vec = np.concatenate([a_n, np.array(ws, dtype=float)])
                nxt += len(ws)
                n_slack += len(ws)
                slack_rows.append((lam_r, ids, a_vec, -float(hi_n)))
            else:
                S = int(np.floor(float(np.maximum(a_n, 0).sum()) - lo_n + 1e-9))
                if S < 0:
                    n_skip += 1
                    continue
                ws = _slack_weights(S, slack)
                ids = np.concatenate([cols.astype(np.int64),
                                      np.arange(nxt, nxt + len(ws),
                                                dtype=np.int64)])
                a_vec = np.concatenate([a_n, -np.array(ws, dtype=float)])
                nxt += len(ws)
                n_slack += len(ws)
                slack_rows.append((lam_r, ids, a_vec, -float(lo_n)))
            n_fb += 1

    n_base = nxt
    if strict_terms:
        quad_terms, n_aux, aux_defs = _quadratize_fast(strict_terms, lam_quad,
                                                       n_base)
    else:
        quad_terms, n_aux, aux_defs = {}, 0, {}
    n_total = n_base + n_aux

    h = np.zeros(n_total, dtype=np.float64)
    h[:n_orig] = np.asarray(inst.c, dtype=np.float64)
    const = float(inst.obj_const)
    qd = {}

    def add_expanded(nodes, coef):
        nonlocal const
        neg = [g for (g, sg) in nodes if g < n_orig and sg < 0]
        pos = [g for (g, sg) in nodes if not (g < n_orig and sg < 0)]
        for rr in range(len(neg) + 1):
            for Sset in combinations(neg, rr):
                c = coef * ((-1) ** rr)
                idx = sorted(pos + list(Sset))
                if len(idx) == 0:
                    const += c
                elif len(idx) == 1:
                    h[idx[0]] += c
                elif len(idx) == 2:
                    i, j = idx
                    qd[(i, j)] = qd.get((i, j), 0.0) + c
                else:
                    raise RuntimeError("装配时出现次数 > 2 的项")

    for k, c in quad_terms.items():
        add_expanded(list(k), c)

    for lam_r, ids, a, d in slack_rows:
        h[ids] += lam_r * (a * a + 2.0 * d * a)
        k = ids.size
        if k < 2:
            const += lam_r * d * d
            continue
        ii, jj = np.triu_indices(k, k=1)
        pi, pj = np.minimum(ids[ii], ids[jj]), np.maximum(ids[ii], ids[jj])
        for i, j, v in zip(pi, pj, 2.0 * lam_r * a[ii] * a[jj]):
            if abs(v) > 1e-12:
                qd[(int(i), int(j))] = qd.get((int(i), int(j)), 0.0) + v
        const += lam_r * d * d

    ri_q, ci_q, vv_q = [], [], []
    for (i, j), c in qd.items():
        if abs(c) < 1e-12:
            continue
        ri_q.append(i)
        ci_q.append(j)
        vv_q.append(c)
    if ri_q:
        Q = coo_matrix((vv_q, (ri_q, ci_q)),
                       shape=(n_total, n_total)).tocsr()
        Q.sum_duplicates()
    else:
        Q = coo_matrix((n_total, n_total)).tocsr()

    return dict(h=h, Q=Q, const=const, n_orig=n_orig, n_aux=n_aux,
                n_slack=n_slack, n_total=n_total, nnz=int(Q.nnz),
                rows_ok=n_strict, rows_fb=n_fb, rows_skip=n_skip,
                rows_ovf=n_ovf, n_base=n_base,
                slack_rows=slack_rows, aux_defs=aux_defs,
                mode=mode, fallback=fallback,
                stats=dict(lam_con=lam_con, lam_quad=lam_quad,
                           K_med=(float(np.median(Ks)) if Ks else 0.0),
                           K_max=(int(max(Ks)) if Ks else 0),
                           n_terms=len(strict_terms)))

def _e_K_from_h(w, K, cap_terms=2_000_000):
    from simplex_build import build_h_m
    acc = {}
    for j in range(1, K + 1):
        hj = build_h_m(w, j, cap_terms)
        if hj is None:
            return None

        for k, v in hj.items():
            acc[k] = acc.get(k, 0.0) + c * v
        if len(acc) > cap_terms:
            return None
    return {k: v for k, v in acc.items() if abs(v) > 1e-12}
```

### A.3 HUBO 编码：混合罚项，不做 Rosenberg 二次化

```python
"""
HUBO 编码：混合罚项（strict e_K + 松弛兜底），**不做 Rosenberg 二次化**
======================================================================
目的：
  绕过二次化，直接得到高阶无约束二值多项式（HUBO）：
      E(x) = c·x + obj_const + Σ_strict侧 λ_con·e_K(v(x)) + Σ_兜底侧 λ_r·(a·x̂+d)²
  变量布局：[0, n_orig) 原变量 | [n_orig, n_base) 松弛变量（仅兜底行需要）。
  **没有辅助变量** —— 这是 HUBO 相对 QUBO 的结构优势（QUBO 版每个高阶项
  需要 len-1 个 Rosenberg 辅助变量，且要保证 aux 取到 lit(n1)·lit(n2)）。

  （负号节点 v = 1-x，一个 k 阶 v-monomial 最多展开成 2^k 个 x-monomial），
  兜底松弛行本身就是二次式，直接展开进同一张项表。

  本文件只负责"构造"；求解（穷举 / 经典 SA）见 hubo_solver.py，
```

### A.4 QAPLIB → HUBO：one-hot 的 strict/兜底 + λ 规则 + 起跑自检

源码：`tests\qaplib\qap_hubo.py`

```python
"""
QAPLIB → HUBO 构建器（不二次化，直接任意阶项表）

QAP: min_{π} Σ_{i,k} A_ik · B_{π(i),π(k)}
二进制化：x_ij = 1 ⟺ 设施 i 放到位置 j（n² 个变量）
  · 目标：Σ_{i,k,j,l} A_ik B_jl x_ij x_kl（二次；互斥对 (i=k 或 j=l) 在可行点上
    恒为 0，为省项数直接跳过——可行点能量不变）
  · one-hot 约束（每设施一行、每位置一行，共 2n 行 Σx = 1）：
      ≤1 侧：strict e_2 = λ·Σ_{a<b} x_a x_b（二次，精确指示，无松弛）
      ≥1 侧：松弛兜底 λ·(Σx - Σ_b 2^b s_b - 1)²（二次，精确指示）
    —— 与 MIPLIB 混合编码同一套"strict 优先 + 兜底"哲学
λ 规则（lam_rule）：
    λ = max_{i,j} ( Σ_k|A_ik| · Σ_l|B_jl| )
推导：目标对 x_ij 单调（系数非负），删掉"设施 i → 位置 j"这一个赋值，
      目标损失 Δobj = Σ_{k,l} A_ik B_jl x_kl ≤ (Σ_k A_ik)(Σ_l B_jl)；
      同时设施行 i、位置列 j 各违 1 行 ≥1 约束，罚增 2λ。
      ⇒ 只要 2λ > Δobj_max，HUBO 全局最优就不可能落在"丢 1 格"的点上。
      λ 取上式（而非 MIPLIB 的 2·cmax）：QAP 目标是 n² 项非负求和，
      丢一格能省 O(n) 项，2·cmax 少了 n 因子 —— 这正是首轮 12/17 实例
      HUBO 全局最优不可行的原因（见 2026-09-27 记忆）。
      另需 2nλ > OPT（压住全零点），本规则实测对 17 实例均满足。

def parse_dat(path):
    toks = open(path).read().replace(",", " ").split()
    n = int(toks[0])
    vals = np.array([int(t) for t in toks[1:]], dtype=np.float64)
    A = vals[:n * n].reshape(n, n)
    B = vals[n * n:n * n + n * n].reshape(n, n)
    return n, A, B

def parse_sln(path):
    toks = open(path).read().replace(",", " ").split()

    perm = np.array([int(t) - 1 for t in toks[2:2 + n]], dtype=np.int64)
    return obj, perm

def qap_obj(A, B, perm):
    return float((A * B[np.ix_(perm, perm)]).sum())

def lam_rule(A, B, opt=None):
    ra = np.abs(A).sum(axis=1)
    rb = np.abs(B).sum(axis=1)
    lam = float(ra.max() * rb.max())
    if opt is not None:
        n = A.shape[0]
        lam = max(lam, 1.1 * float(opt) / (2.0 * n))
    return lam

def build_qap_hubo(A, B, lam=None):
    n = A.shape[0]
    n2 = n * n
    terms = {}
    const = 0.0

    def add(key, coef):
        if abs(coef) < 1e-12:
            return
        terms[key] = terms.get(key, 0.0) + coef

    nzA = [(i, k, A[i, k]) for i in range(n) for k in range(n)
           if A[i, k] != 0]
    nzB = [(j, l, B[j, l]) for j in range(n) for l in range(n)
           if B[j, l] != 0]
    cmax = 1.0
    for i, k, a in nzA:
        for j, l, b in nzB:
            c = a * b
            u, v = i * n + j, k * n + l
            if u == v:
                add((u,), c)
                cmax = max(cmax, abs(c))
            elif i == k or j == l:
                continue
            else:
                add((min(u, v), max(u, v)), c)
                cmax = max(cmax, abs(c))
    n_obj_terms = len(terms)

    if lam is None:
        lam = lam_rule(A, B)

    rows = []
    for i in range(n):
        rows.append([i * n + j for j in range(n)])
    for j in range(n):
        rows.append([i * n + j for i in range(n)])

    nbits = max(1, (n - 1).bit_length())
    n_slack = 2 * n * nbits
    sid0 = n2
    row_slack = []

    for rv in rows:
        for a_i in range(len(rv)):
            for b_i in range(a_i + 1, len(rv)):
                add((rv[a_i], rv[b_i]), lam)

    for r_i, rv in enumerate(rows):
        sl = list(range(sid0 + r_i * nbits, sid0 + (r_i + 1) * nbits))
        row_slack.append(sl)
        zu = [(u, 1.0) for u in rv] + \
             [(s, -float(1 << b)) for b, s in enumerate(sl)]
        for u, cu in zu:
            add((u,), lam * (cu * cu - 2.0 * cu))
            for v, cv in zu:
                if v > u:
                    add((u, v), lam * 2.0 * cu * cv)
        const += lam
    deg = max(len(k) for k in terms)
    return dict(terms=terms, const=const, n_total=n2 + n_slack,
                n2=n2, n=n, n_slack=n_slack, lam=lam, cmax=cmax,
                stats=dict(n_terms=len(terms), n_obj=n_obj_terms,
                           deg_max=deg, n_rows=2 * n, nbits=nbits))

def x_of_perm(perm, n_total):
    x = np.zeros(n_total, dtype=np.int8)
    n = len(perm)
    for i, j in enumerate(perm):
        x[i * n + j] = 1
    return x

def sln_perm(name, A, B, ret_obj=False):

def feasible_rows(x, n):
    X = x[:n * n].reshape(n, n)
    return np.concatenate([X.sum(axis=1), X.sum(axis=0)])

def preflight(A, B, m, perm, lam, n_total, n_sample=120, seed=0):
    n = A.shape[0]
    opt = qap_obj(A, B, perm)
    tol = 1e-9 * max(abs(opt), 1.0)
    x_opt = x_of_perm(perm, n_total)
    E_opt = float(m.energy(x_opt))
    ok1 = abs(E_opt - opt) <= tol

    E_zero = float(m.energy(np.zeros(n_total, dtype=np.int8)))
    ok2 = E_zero > opt + tol

    dmin, darg, nbad3 = np.inf, None, 0
    for i in range(n):
        x = x_opt.copy()
        x[i * n + perm[i]] = 0
        E = float(m.energy(x))
        if E < dmin:
            dmin, darg = E, (i, int(perm[i]))
        if E <= opt + tol:
            nbad3 += 1
    ok3 = nbad3 == 0

    rng = np.random.RandomState(seed)
    smin, nbad4, nfeas, nfeas_bad = np.inf, 0, 0, 0
    for _ in range(n_sample):
        k = int(rng.randint(1, n + 1))
        facs = rng.choice(n, size=k, replace=False)
        x = x_opt.copy()
        for i in facs:
            x[i * n + perm[i]] = 0
            x[i * n + int(rng.randint(n))] = 1
        if (feasible_rows(x, n) == 1).all():
            nfeas += 1
            if qap_obj(A, B, np.array([int(np.argmax(x[i * n:(i + 1) * n]))
                                       for i in range(n)])) < opt - tol:
                nfeas_bad += 1
            continue
        E = float(m.energy(x))
        if E < smin:
            smin = E
        if E <= opt + tol:
            nbad4 += 1
    ok4 = (nbad4 == 0 and nfeas_bad == 0)

    info = dict(ok=bool(ok1 and ok2 and ok3 and ok4),
                E_opt=E_opt, opt=opt, E_zero=E_zero, zero_over_opt=E_zero - opt,
                drop1_min=dmin, drop1_arg=darg, drop1_over_opt=dmin - opt,
                drop1_bad=nbad3, samp_min=smin, samp_over_opt=smin - opt,
                samp_bad=nbad4, samp_feas=nfeas, samp_feas_bad=nfeas_bad,
                lam=float(lam))
    return info["ok"], info
```

### A.5 独立解校验器：自带解析器复算，违反行数 = 0 才判定可行

```python
"""
独立解校验器（不复用求解器任何代码）
====================================
输入：MPS 实例文件 + 原始变量空间解文件（.sol，格式 "=obj= v" + "变量名 值"）
输出：逐行复算约束，报告 违反行数 / 最大违约 / 总违约 / 独立复算目标值，并给出判定

设计要点：
- 自带独立的最小 MPS 解析器（ROWS/COLUMNS/RHS/RANGES/BOUNDS），与求解器的解析器
  完全分离，避免"同一处 bug 被两边共用"而误判可行
- 独立处理 RANGES 与 E/L/G 行型，缺失变量按 0 处理
- 若 MPS 目标方向为 MAX，复算值按原始方向报告，同时给出最小化口径

用法：
  python verify_sol.py <inst.mps> <inst.sol> [--tol 1e-6]
退出码：0=严格可行，1=不可行，2=错误
"""

import argparse
import gzip
import io
import sys

if sys.platform == "win32":
    sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding="utf-8",
                                  errors="replace")

def parse_mps_min(path):
    opener = gzip.open if path.endswith(".gz") else open
    section = None
    row_type, row_order = {}, []
    obj_row = None
    cols = []
    colset = set()
    obj = {}
    rows = []
    rhs, ranges = {}, {}
    bounds = {}
    objsense = "min"
    with opener(path, "rt", encoding="utf-8", errors="ignore") as f:
        for raw in f:
            line = raw.rstrip("\n")
            if not line.strip() or line.lstrip().startswith("*"):
                continue
            if line[0] not in " \t":
                section = line.split()[0].upper()
                continue
            p = line.split()
            if section == "OBJSENSE":
                objsense = p[0].lower()
            elif section == "ROWS":
                if p[0] == "N":
                    if obj_row is None:
                        obj_row = p[1]
                else:
                    row_type[p[1]] = p[0]
                    row_order.append(p[1])
            elif section == "COLUMNS":
                if "MARKER" in line.upper():
                    continue
                c = p[0]
                if c not in colset:
                    colset.add(c)
                    cols.append(c)
                for k in range(1, len(p) - 1, 2):
                    rn, val = p[k], float(p[k + 1])
                    if rn == obj_row:
                        obj[c] = obj.get(c, 0.0) + val
                    else:
                        rows.append((rn, c, val))
            elif section == "RHS":
                for k in range(1, len(p) - 1, 2):
                    if p[k] != obj_row:
                        rhs[p[k]] = rhs.get(p[k], 0.0) + float(p[k + 1])
            elif section == "RANGES":
                for k in range(1, len(p) - 1, 2):
                    ranges[p[k]] = float(p[k + 1])
            elif section == "BOUNDS":
                b = bounds.setdefault(p[2] if len(p) > 2 else p[1], {})
                t = p[0].upper()
                v = None
                if len(p) > 3:
                    try:
                        v = float(p[3])
                    except ValueError:
                        v = None
                if t == "FX":
                    b["fx"] = v
                elif t == "LO":
                    b["lo"] = v
                elif t == "UP":
                    b["up"] = v
                elif t == "BV":
                    b["lo"], b["up"] = 0.0, 1.0
                elif t == "MI":
                    b["lo"] = float("-inf")
                elif t == "PL":
                    b["up"] = float("inf")
    return objsense, row_type, row_order, rows, rhs, ranges, obj, bounds, cols

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("mps")
    ap.add_argument("sol")
    ap.add_argument("--tol", type=float, default=1e-6)
    a = ap.parse_args()

    objsense, row_type, row_order, trips, rhs, ranges, obj, bounds, cols = \
        parse_mps_min(a.mps)

    xval, sol_obj = {}, None
    for line in open(a.sol, encoding="utf-8", errors="ignore"):
        s = line.strip()
        if not s:
            continue
        if s.startswith("="):
            toks = s.replace("=", " ").split()
            for i, t in enumerate(toks):
                if t.lower() in ("obj", "objective") and i + 1 < len(toks):
                    sol_obj = float(toks[i + 1])
                    break
            continue
        p = s.split()
        if len(p) == 2:
            try:
                xval[p[0]] = float(p[1])
            except ValueError:
                pass

    lhs = {r: 0.0 for r in row_order}
    for rn, c, v in trips:
        xv = xval.get(c)
        if xv:
            lhs[rn] = lhs.get(rn, 0.0) + v * xv

    nbad, max_viol, tot_viol = 0, 0.0, 0.0
    worst = None
    for rn in row_order:
        v = lhs.get(rn, 0.0)
        R = rhs.get(rn, 0.0)
        t = row_type[rn]
        rg = ranges.get(rn)
        if t == "E":
            lo = hi = R
            if rg:
                lo, hi = (R, R + abs(rg)) if rg > 0 else (R - abs(rg), R)
        elif t == "L":
            hi = R
            lo = R - abs(rg) if rg else float("-inf")
        else:
            lo = R
            hi = R + abs(rg) if rg else float("inf")
        viol = max(0.0, v - hi) + max(0.0, lo - v)
        if viol > a.tol:
            nbad += 1
            tot_viol += viol
            if viol > max_viol:
                max_viol, worst = viol, (rn, v, lo, hi)

    obj_val = sum(obj.get(c, 0.0) * xval.get(c, 0.0) for c in cols)
    nb_bad = 0
    for c in cols:
        xv = xval.get(c, 0.0)
        b = bounds.get(c, {})
        lo = b.get("lo", 0.0)
        hi = b.get("up", 1.0)
        if "fx" in b:
            lo = hi = b["fx"]
        if xv < lo - a.tol or xv > hi + a.tol:
            nb_bad += 1

    print(f"实例: {a.mps}")
    print(f"解文件: {a.sol}")
    print(f"变量数(文件出现): {len(cols)}  解中非零变量: {len(xval)}")
    print(f"目标方向: {objsense.upper()}")
    print(f"解文件声明目标: {sol_obj}")
    print(f"独立复算目标:   {obj_val:.10g}  差异: "
          f"{'N/A' if sol_obj is None else f'{abs(obj_val - sol_obj):.3g}'}")
    print(f"越界变量数: {nb_bad}")
    print(f"违反行数: {nbad} / {len(row_order)}")
    print(f"最大单行违约: {max_viol:.6g}  总违约: {tot_viol:.6g}")
    if worst:
        print(f"  最差行: {worst[0]}  lhs={worst[1]:.6g} 区间=[{worst[2]}, {worst[3]}]")
    ok = (nbad == 0 and nb_bad == 0)
    print("判定:", "严格可行（FEASIBLE）" if ok else "不可行（INFEASIBLE）")
    return 0 if ok else 1

if __name__ == "__main__":
    sys.exit(main())
```

```python
"""
MIPLIB hard 实例 × 一元松弛不等式编码（x 空间闭式实现）SA 测试
============================================================

编码原理（docs/qubo_inequality_encoding.md）：
  线性约束 Σ a_i x_i <= / >= / = C 编码为 QUBO 罚项
      P · (Σ a_i x_i + y − C)²   (le, y∈{0,1}^C 一元松弛)
      P · (Σ a_i x_i − y − C)²   (ge)
  一元松弛的 min_y 有闭式 max(0, viol)²，经典求解器可整体消去 y 块，
  在 x 空间直接搜索（本项目 2026-09-11 高维验证 26/26 PASS 的最优实践）。
  本脚本即该闭式实现：
      E(x) = c·x + Σ_r λ_r · viol_r(x)²
      viol_r(x) = max(0, lhs_r − ub_r) + max(0, lb_r − lhs_r)
  （双向违约之和，同时覆盖 le/ge/eq 与 RANGES 行）

      → 与 MIPLIB 最优已知值对比 gap

用法：python miplib_sa_test.py [每实例时间预算秒] [实例名...]
日志：run_log.txt（追加）；进度：progress.json（周期覆盖）；结果：results.md
```

```python
def viol(self, lhs):
        v = np.maximum(0.0, lhs - self.ub) + np.maximum(0.0, self.lb - lhs)
        v[~np.isfinite(self.lb) & ~np.isfinite(self.ub)] = 0.0
        return v
```

**A.6.3 `sa_cycle`** —— 多周期回热 SA 单周期：单翻转 / 交换移动 + 增量 ΔE

```python
def sa_cycle(inst, x, lhs, v, obj, lamv, T0, Tmin, iters, deadline, rng,
             best_f_obj, best_f_x, prog, t_start, flips_total, name):
    cs, ce = inst.col_start[:-1], inst.col_start[1:]
    Tmin = max(1e-9, Tmin)
    alpha = (Tmin / T0) ** (1.0 / max(1, iters))
    T = T0
    total_v = float(v.sum())
    ones = IdxSet(x > 0)
    zeros = IdxSet(x < 1)
    obj0 = best_f_obj[0]
    it = 0
    while it < iters and time.time() < deadline:
        it += 1
        if it % 2048 == 0 and prog is not None:
            prog(name, "anneal", flips_total[0], time.time() - t_start,
                 best_f_obj[0], total_v, float(lamv.mean()), T)
        if (SWAP_PROB > 0 and ones.n > 0 and zeros.n > 0
                and rng.random() < SWAP_PROB):
            k1 = int(ones.idx[rng.integers(ones.n)])
            k2 = int(zeros.idx[rng.integers(zeros.n)])
            s1, s2 = slice(cs[k1], ce[k1]), slice(cs[k2], ce[k2])
            rws = np.concatenate([inst.ri[s1], inst.ri[s2]])
            aws = np.concatenate([-inst.av[s1], inst.av[s2]])
            uniq, inv = np.unique(rws, return_inverse=True)
            agg = np.zeros(uniq.size)
            np.add.at(agg, inv, aws)
            old = v[uniq]
            nv = _viol_at(inst, lhs[uniq] + agg, uniq)
            d_obj = inst.c[k2] - inst.c[k1]
            dE = d_obj + float((lamv[uniq] * (nv * nv - old * old)).sum())
            if dE <= 0 or rng.random() < math.exp(-dE / T):
                x[k1], x[k2] = 0, 1
                lhs[uniq] += agg
                v[uniq] = nv
                obj[0] += d_obj
                total_v = float(v.sum())
                flips_total[0] += 1
                ones.update(k1, False)
                zeros.update(k1, True)
                zeros.update(k2, False)
                ones.update(k2, True)
                if total_v <= inst.tol and (best_f_obj[0] is None
                                            or obj[0] < best_f_obj[0]):
                    best_f_obj[0] = obj[0]
                    best_f_x[0] = x.copy()
        else:
            k = int(rng.integers(inst.n))
            sgn = 1 - 2 * x[k]
            seg = slice(cs[k], ce[k])
            rws, aws = inst.ri[seg], inst.av[seg] * sgn
            old = v[rws]
            nv = _viol_at(inst, lhs[rws] + aws, rws)
            dE = inst.c[k] * sgn + float((lamv[rws] * (nv * nv - old * old)).sum())
            if dE <= 0 or rng.random() < math.exp(-dE / T):
                x[k] ^= 1
                lhs[rws] += aws
                v[rws] = nv
                obj[0] += inst.c[k] * sgn
                total_v = float(v.sum())
                flips_total[0] += 1
                if sgn > 0:
                    zeros.update(k, False)
                    ones.update(k, True)
                else:
                    ones.update(k, False)
                    zeros.update(k, True)
                if total_v <= inst.tol and (best_f_obj[0] is None
                                            or obj[0] < best_f_obj[0]):
                    best_f_obj[0] = obj[0]
                    best_f_x[0] = x.copy()
        T *= alpha
    improved = (best_f_obj[0] is not None
                and (obj0 is None or best_f_obj[0] < obj0 - 1e-12))
    return total_v, improved
```

**A.6.4 `sa_solve`** —— 两阶段主流程：初值竞选 → 回热循环 → 抛光

```python
def sa_solve(inst, budget_s, seed=12345, prog=None, x_init=None, x_warm=None,
             x_known=None):
    rng = np.random.default_rng(seed)
    t_start = time.time()
    t_end = t_start + budget_s
    t_rep = min(t_end, t_start + budget_s * REPAIR_SHARE)
    inits = []
    if x_known is not None:
        inits.append(np.asarray(x_known, dtype=np.int8).copy())
    if x_warm is not None:
        inits.append(np.asarray(x_warm, dtype=np.int8).copy())
    if x_init is not None:
        inits.append(np.asarray(x_init, dtype=np.int8).copy())
        xl = np.asarray(x_init, dtype=float)
        for thr in (0.25, 0.5, 0.75):
            inits.append((rng.random(inst.n) < xl + (thr - 0.5) * 0.8
                          ).astype(np.int8))
    inits.append(np.ones(inst.n, dtype=np.int8))
    inits.append(np.zeros(inst.n, dtype=np.int8))
    inits.append((rng.random(inst.n) < 0.5).astype(np.int8))

    feas = False
    best_repair_v, best_repair_x = np.inf, None
    for init in inits:
        if feas or time.time() >= t_rep:
            break
        x = init
        lhs = inst.lhs_init(x)
        v = inst.viol(lhs)
        if greedy_repair(inst, x, lhs, v, t_rep, rng):
            feas, bv, bx = True, 0.0, x.copy()
        else:
            feas, wf, bv, bx = walksat(inst, x, lhs, v, t_rep, rng)
        if bv < best_repair_v:
            best_repair_v, best_repair_x = bv, bx
    log(f"  {inst.name} WalkSAT修复: 可行={feas} "
        f"最好viol={best_repair_v:.4g} 耗时={time.time()-t_start:.1f}s")
    if feas:
        x = bx
    else:
        x = best_repair_x.copy()
    lhs = inst.lhs_init(x)
    v = inst.viol(lhs)
    obj = [float(inst.c @ x)]
    best_f_obj, best_f_x = [None], [None]
    flips_total = [0]
    if feas:
        best_f_obj[0] = obj[0]
        best_f_x[0] = x.copy()

    lam_scale = 1.0
    Tmin_cycle = 0.01 * max(1.0, inst.cmax)
    T0_full = max(1.0, inst.cmax)
    rep_cap = max(10.0, min(60.0, 0.08 * budget_s))
    pol_cap = max(3.0, min(20.0, 0.03 * budget_s))
    cyc = 0
    stall = 0
    t_sa_end = t_end - budget_s * LNS_FRAC if LNS_FRAC > 0 else t_end
    while time.time() < t_sa_end:
        cyc += 1
        lamv = lam_scale * inst.lam_row
        T0 = T0_full * (1.0 + 0.5 * stall) if stall else T0_full * 0.5
        T0 = min(T0, 4.0 * T0_full)
        iters = 200_000
        dl = min(t_sa_end, time.time() + max(5.0, budget_s * 0.25))
        if best_f_x[0] is not None and stall >= 1:
            x[:] = best_f_x[0]
            if stall >= 3:
                pert = rng.choice(inst.n, size=max(1, inst.n // (20 * stall)),
                                  replace=False)
                x[pert] ^= 1
            lhs[:] = inst.lhs_init(x)
            v[:] = inst.viol(lhs)
            obj[0] = float(inst.c @ x)
        tv, improved = sa_cycle(inst, x, lhs, v, obj, lamv, T0, Tmin_cycle,
                                iters, dl, rng, best_f_obj, best_f_x, prog,
                                t_start, flips_total, inst.name)
        if improved:
            stall = 0
        else:
            stall += 1
        if tv > inst.tol and time.time() < t_sa_end:
            if best_f_x[0] is not None and tv > best_repair_v:
                x[:] = best_f_x[0]
                lhs[:] = inst.lhs_init(x)
                v[:] = inst.viol(lhs)
                obj[0] = float(inst.c @ x)
                tv = float(v.sum())
            elif (best_f_x[0] is None and best_repair_x is not None
                  and tv > best_repair_v):
                x[:] = best_repair_x
                lhs[:] = inst.lhs_init(x)
                v[:] = inst.viol(lhs)
                tv = best_repair_v
            if tv > inst.tol:
                dl2 = min(t_sa_end, time.time() + rep_cap)
                if greedy_repair(inst, x, lhs, v, dl2, rng):
                    feas2, bv2, bx2 = True, 0.0, x.copy()
                else:
                    feas2, _, bv2, bx2 = walksat(inst, x, lhs, v, dl2, rng)
                if bv2 < best_repair_v:
                    best_repair_v, best_repair_x = bv2, bx2
                if feas2:
                    obj[0] = float(inst.c @ x)
                    if best_f_obj[0] is None or obj[0] < best_f_obj[0]:
                        best_f_obj[0], best_f_x[0] = obj[0], x.copy()
                    log(f"  {inst.name} 周期{cyc} 补修复成功 obj={obj[0]:.6g}")
                else:
                    lam_scale *= LAMBDA_GROW
        if best_f_x[0] is not None and time.time() < t_end:
            x[:] = best_f_x[0]
            lhs[:] = inst.lhs_init(x)
            v[:] = inst.viol(lhs)
            new_obj, pol_n = polish(inst, x, lhs, v,
                                    min(t_end, time.time() + pol_cap), rng)
            if (pol_n and float(v.sum()) <= inst.tol
                    and new_obj < best_f_obj[0] - 1e-12):
                best_f_obj[0], best_f_x[0] = new_obj, x.copy()
                log(f"  {inst.name} 周期{cyc} 抛光改进 -> {new_obj:.8g}"
                    f"（{pol_n} 步）")
        if cyc % 4 == 0 or tv > inst.tol or improved:
            log(f"  {inst.name} 周期{cyc} lam_scale={lam_scale:.3g} T0={T0:.3g} "
                f"viol={tv:.3g} best={best_f_obj[0]} stall={stall} "
                f"翻转={flips_total[0]/1e6:.1f}M elapsed={time.time()-t_start:.0f}s")
    lns_it = 0
    if LNS_FRAC > 0 and best_f_x[0] is not None and time.time() < t_end:
        x[:] = best_f_x[0]
        lhs[:] = inst.lhs_init(x)
        v[:] = inst.viol(lhs)
        obj[0] = float(inst.c @ x)
        before = best_f_obj[0]
        lns_refine(inst, x, 0, rng, lam_scale * inst.lam_row,
                   best_f_obj, best_f_x, deadline=t_end, prog=prog,
                   t_start=t_start, name=inst.name)
        if best_f_obj[0] is not None and best_f_obj[0] < before - 1e-12:
            log(f"  {inst.name} LNS 精修改进: {before:.8g} -> "
                f"{best_f_obj[0]:.8g}")

    pol_moves = 0
    if best_f_x[0] is not None and time.time() < t_end:
        x[:] = best_f_x[0]
        lhs[:] = inst.lhs_init(x)
        v[:] = inst.viol(lhs)
        obj[0] = float(inst.c @ x)
        new_obj, pol_moves = polish(inst, x, lhs, v, t_end, rng)
        if new_obj < best_f_obj[0] - 1e-12 and float(v.sum()) <= inst.tol:
            best_f_obj[0], best_f_x[0] = new_obj, x.copy()
            log(f"  {inst.name} 抛光改进: {new_obj:.8g}（移动 {pol_moves} 次）")
    return dict(feasible=best_f_obj[0] is not None, obj=best_f_obj[0],
                x=best_f_x[0], flips=flips_total[0], lam=lam_scale,
                polish_moves=pol_moves, repair_ok=feas)
```
