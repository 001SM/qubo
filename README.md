## 三、论文的三条核心结论

1. **编码正确性可逐点验证**：低维穷举 + 高维三件套 26/26 + HUBO 罚项 70/70 项检查通过。
2. **邻域结构比编码更决定成败**：QAPLIB 上同一编码、同一实例，perm（swap 邻域）600s
   命中 120/136 = 88.2%；换成通用单点翻转，可行任务从 136 掉到 9、命中 0。
3. **闭式消元让经典侧零辅助变量**：n=60 背包（DP 最优 2668），朴素 SA 退火完整 QUBO
   gap 39%，x 空间 SA + 解析罚 gap 0%；相对二次化省下约 40 万辅助变量。

## 四、明确写入论文的局限（未粉饰）

- 大规模 MIPLIB 仍不可用：ramos3 gap 941%（罚项淹没目标）、d20200 / t1722 不可行。
- 坐标级多数投票与 one-hot 结构系统性冲突（d20200 8/8 全败，机制已定位、修法明确但未实施）。
- HUBO 项数随阶数 K 指数增长。
- 未与 SOTA 求解器对比，只对比经典求解器（SA / ILS / tabu / greedy）。
